## 記入例：お小遣い手帳アプリ

### 1. どんなアプリ？
- **アプリの名前** → おこづかい手帳
- **ひとことで説明すると** → お小遣いの出入りを記録して、あといくら使えるか見れるアプリ
- **だれが使う？** → 自分（小学生）
- **なにに使う？** → 毎月のお小遣いの管理

### 2. どんな画面がある？

**画面①**
- 画面の名前 → ホーム（残高画面）
- なにが見える？ → 今の残高、今月使った合計、最近の記録3件
- なにができる？ → 記録を追加するボタンを押せる

**画面②**
- 画面の名前 → 記録をつける画面
- なにが見える？ → 入力フォーム
- なにができる？ → 日付、金額、もらった/つかった、メモを入力して保存

**画面③**
- 画面の名前 → 履歴画面
- なにが見える？ → 全部の記録が新しい順に並ぶ
- なにができる？ → 記録を消す、月ごとにフィルター

### 3. データ
| おぼえるもの | どんな内容？ | 例 |
|---|---|---|
| 記録 | 日付・金額・種類・メモ | 7/1, 500円, もらった, お小遣い |
| 残高 | 今いくらあるか | 1,200円 |
| 目標 | 貯金の目標金額 | 3,000円 |

### 4. やりたいこと
| やりたいこと | くわしく | 優先度 |
|---|---|---|
| 記録をつける | 収入・支出を入力して保存 | ★★★ |
| 残高を見る | 自動で計算して表示 | ★★★ |
| 履歴を見る | 過去の記録を一覧表示 | ★★★ |
| 目標を設定 | 目標金額を決めて進捗バー表示 | ★★ |
| グラフ | 月ごとの推移をグラフで見る | ★ |

### 5. 見た目のイメージ
- 色 → 緑っぽい、お金のイメージ
- 参考 → なし
- スケッチ → なし

### 6. ルール
- マイナスの金額は入力できない
- 日付は未来の日付は選べない
- 記録を消すときは「本当に消す？」と確認する

### 7. 技術メモ
| 項目 | 選択 |
|---|---|
| 動く場所 | ブラウザ |
| データ保存 | ブラウザに保存（localStorage） |
| ログイン | なし |
| 使う言語 | HTML+JS |
