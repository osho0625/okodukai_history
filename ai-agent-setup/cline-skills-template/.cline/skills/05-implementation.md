# Skill: Implementation（実装 + ミニレビュー）

## 手順（1タスクごと）

### 準備（.clinerules「実装前チェック」に従い必ず実施）

1. tasks.md からタスク内容を確認する
2. 対象ファイル全体を読む
3. 定義元・呼び出し元・呼び出し先・共通モジュールを確認する
4. 同じ実装が既にないか検索する

### 実装

5. コードを書く
6. 動作確認（テストあり → 実行 / なし → エラーなし確認）
7. 問題あれば修正（3回ルール適用）

### ミニレビュー

8. 共通DoDチェック:
   - [ ] 完了条件を満たしている
   - [ ] Build/実行エラーなし
   - [ ] 既存テストが壊れていない
   - [ ] デバッグコードなし
   - [ ] 次タスクへの悪影響なし（共有state、グローバル副作用、CSS影響）
9. タスク固有DoDがあれば確認
10. tasks.md を `[x]` に更新
11. 次タスクへ

### 全タスク完了後

12. 「全タスク完了。最終レビューに進みます」と報告

## 禁止事項

- 対象ファイルを読まずに書き始めない
- 複数タスクを一度に実装しない
- ミニレビューをスキップしない
- 設計書にない機能を追加しない
- テストが落ちたまま次に進まない
- 既存コメント・コメントアウトを勝手に削除しない
