# Skill: Final Review

## 手順

1. requirements.md から **FR-* と AC-* の一覧のみ** 確認する（概要・ストーリー等は再読しない）
2. design.md から **ファイル構成・データ設計・処理フロー** のみ確認する（他セクション不要）
3. decision-log.md を確認する（存在する場合のみ）
4. 実装コードを確認する
5. 下記チェックリストを実施する
6. 結果をユーザーに報告する

## チェックリスト

### 要件
- [ ] 全FR-*実装済み
- [ ] 全AC-*充足
- [ ] スコープ外混入なし

### 設計
- [ ] ファイル構成が設計通り
- [ ] データ設計通り
- [ ] エラーハンドリング設計通り

### 品質
- [ ] 不要コード（console.log等）なし
- [ ] セキュリティリスクなし
- [ ] パフォーマンス問題なし

### 統合
- [ ] 正常系が動作する
- [ ] エラーケースでクラッシュしない

### Decision Log（存在する場合）
- [ ] 判断が実装に反映されている

## 出力フォーマット

```markdown
# 最終レビュー結果

## 要件充足
| 要件ID | ✅/⚠️ | 備考 |

## 設計乖離
- ☑ なし / ☐ あり: {内容}

## 品質
- ☑ 問題なし / ☐ 要修正: {内容}

## 総合判定
✅ 完了 / ⚠️ 要修正（{概要}）
```

## 問題発見時

| 重要度 | 対応 |
|--------|------|
| コード修正で対応可 | 即修正 |
| セキュリティ問題 | 即修正 |
| 設計変更が必要 | ユーザーに報告 |
| nice-to-have | 報告のみ（Issue提案） |

## 禁止事項

- レビューをスキップしない
- 設計変更を伴う修正をユーザー確認なしで行わない
- 要件にない改善を勝手に実施しない
