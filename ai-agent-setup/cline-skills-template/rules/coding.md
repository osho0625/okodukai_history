# コーディング規約（詳細 - テスト作成・レビュー時に参照）

※ コア規約は .clinerules に記載。ここは補足のみ。

## 命名規則

- 変数・関数: camelCase
- クラス・コンポーネント: PascalCase
- 定数: UPPER_SNAKE_CASE
- ファイル名: kebab-case（プロジェクトの慣習に従う）

## コメント

- 「何をしているか」ではなく「なぜそうしているか」を書く
- 複雑なビジネスロジックには必ずコメントを残す
- TODOコメントは残さない（今解決するか、Issue化する）
- 既存コメントは原則削除しない
- コメントアウトもユーザー指示が無い限り削除しない

## エラーハンドリング

- try-catch で握りつぶさない（最低限ログを出す）
- ユーザー向けエラーメッセージは具体的かつ親切に
- APIエラーはステータスコードに応じた処理

## セキュリティ

- ユーザー入力は必ずサニタイズする
- パスワード・APIキーをハードコードしない
- innerHTML の使用は最小限に（XSS対策）
