# レビュー観点

プロジェクトに配置する場合は `.clinerules/review.md` にコピーする。

## コードレビュー観点

### 正確性
- 要件通りに動作するか
- エッジケースが考慮されているか
- オフバイワンエラーがないか

### セキュリティ
- XSS（クロスサイトスクリプティング）の脆弱性がないか
- SQLインジェクションの可能性がないか
- 認証・認可の漏れがないか
- 機密情報がログや画面に露出していないか

### パフォーマンス
- N+1クエリが発生していないか
- 不要なリクエストやレンダリングがないか
- 大量データ処理時にメモリリークがないか

### 保守性
- コードが読みやすいか（6ヶ月後の自分が理解できるか）
- 適切に関数/モジュールが分割されているか
- マジックナンバーが定数化されているか

### テスタビリティ
- テストが書かれている（または書ける構造になっている）か
- 外部依存がモック可能か
