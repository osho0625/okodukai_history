# レビュー観点（詳細 - レビュー時のみ参照）

## チェックリスト

### 正確性
- [ ] 要件通りに動作する
- [ ] エッジケース考慮済み
- [ ] オフバイワンエラーなし

### セキュリティ
- [ ] XSS脆弱性なし
- [ ] SQLインジェクションなし
- [ ] 認証・認可の漏れなし
- [ ] 機密情報の露出なし

### パフォーマンス
- [ ] N+1クエリなし
- [ ] 不要なリクエスト・レンダリングなし
- [ ] メモリリスクなし

### 保守性
- [ ] 6ヶ月後の自分が理解できる
- [ ] 適切にモジュール分割されている
- [ ] マジックナンバー定数化済み

### テスタビリティ
- [ ] テストが書かれている（書ける構造）
- [ ] 外部依存がモック可能
