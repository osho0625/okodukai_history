## テスト1: バグ再現テストの再実行（主テスト）

### 目的

3. `apm run setup-kiro-win` を実行する

### 期待結果
- exit code 0 で正常終了する
- エラーメッセージが表示されない

### 判定基準
- `apm run` がエラーなく完了し、`[X] Script execution error` が表示されないこと

## テスト6: git clone 後のエンコーディング保全確認

### 目的
.gitattributes により、別環境での git clone 後も setup-local.bat のエンコーディングが保全されることを確認する

### 防ぐバグ
git の自動改行変換によるファイル破損の再発

### 手順
1. 修正版がリモートリポジトリに push 済みであることを確認する
2. 別ディレクトリで `git clone` を実行する
3. クローンした setup-local.bat の先頭バイトを確認する（BOM なし UTF-8）
4. `chcp 65001 >nul` が2行目に存在することを確認する
5. 改行コードが CRLF であることを確認する

### 期待結果
- UTF-8（BOM なし）+ CRLF + `chcp 65001 >nul` の構成が維持されている

### 判定基準
- `file setup-local.bat` で `UTF-8 Unicode text, with CRLF line terminators` と表示されること
