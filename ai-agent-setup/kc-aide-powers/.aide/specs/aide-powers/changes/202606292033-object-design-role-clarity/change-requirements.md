# 変更要求定義

## 変更概要

- **変更の目的・背景**: オブジェクト設計ドキュメントにおいて、外部ツール・外部サービスと連携する部分の設計が、公式ドキュメントベースの技術調査結果に基づいて行われていることを保証したい。現状は、外部連携部分の設計時に技術調査を行っても、その調査結果や公式ドキュメントへのリンクが設計書に記録として残らないため、設計が最新の公式仕様に基づいているかどうかを後から検証できない状態になっている。
- **変更種別**: 複合（テンプレートへの記載欄追加＝機能追加、設計書作成プロセスへのステップ追加＝仕様変更、レビュー観点追加＝仕様変更）

## 要求事項

### REQ-C-001: オブジェクト設計ドキュメントへの技術調査結果・公式ドキュメントリンク記載欄の追加

- **種別**: 追加
- **説明**: オブジェクト設計ドキュメント（object-design-*.md）のうち、外部ツール・外部サービスと連携する部分の設計を記述するセクション（関連オブジェクト設計等）に、技術調査結果の要約と参照した公式ドキュメントへのリンクを記載する欄を新設する。
- **受入基準**:
  - AC-001: 外部連携部分の設計を含むオブジェクト設計ドキュメントに、「技術調査結果」および「参考ドキュメント（URLリンク付き）」を記載する欄が存在すること
  - AC-002: 当該欄には最低1件のURL形式のリンクを記載できる構造になっていること
- **優先度**: 必須

### REQ-C-002: 設計書作成プロセス（object-designスキル）への技術調査ステップの追加

- **種別**: 変更
- **説明**: object-designスキルの設計書作成プロセスにおいて、外部ツール・外部サービスと連携する部分を設計する際は、tech-investigationスキルを用いて公式ドキュメントベースの技術調査を実施し、その調査結果と参照リンクをREQ-C-001の記載欄に反映するステップを追加する。
- **受入基準**:
  - AC-003: object-designスキルの設計プロセス記述に、外部連携部分について技術調査を実施するステップが明記されていること
  - AC-004: 当該ステップの完了後、対象オブジェクト設計ドキュメントの記載欄（REQ-C-001）に調査結果とリンクが反映される、とプロセス上で規定されていること
- **優先度**: 必須

### REQ-C-003: レビュー観点（object-design-qa-agent）への公式ドキュメント整合性検証の追加

- **種別**: 変更
- **説明**: object-design-qa-agentのレビュー検証項目に、外部連携部分の設計について、技術調査結果と公式ドキュメントへのリンクが記載されているか、および記載内容が設計内容と整合しているかを検証する観点を追加する。
- **受入基準**:
  - AC-005: object-design-qa-agentの検証項目一覧に、外部連携部分のリンク記載有無・内容整合性を確認する項目が追加されていること
  - AC-006: 当該項目が既存の判定基準（FAIL=0 かつ WARNING=0 → APPROVED）の枠組みに統合され、リンク未記載または内容不整合の場合はFAILまたはWARNINGとして判定されること
- **優先度**: 必須

## 対象外（スコープ外）

- 影響範囲分析および具体的な設計差分（before→after）の策定（後続の影響範囲分析・対応方針策定工程で実施する）
- 既存プロジェクトの既存 object-design-*.md への遡及的なリンク追加（本変更は今後作成・更新される設計書に適用する仕組みの追加であり、既存ドキュメントの一括更新は対象外）
- tech-investigationスキル自体の調査手法・Web検索ロジックの変更（既存の調査機能をそのまま呼び出す前提とする）
- 「何が外部ツール・外部サービス連携に該当するか」の判定基準の新規策定（既存のオブジェクト設計フェーズでの判断に委ねる）

## 前提条件

- object-design スキル（skills/object-design/SKILL.md）、object-design-qa-agent（agents/object-design-qa-agent.md 等）、tech-investigation スキル（skills/tech-investigation/SKILL.md）が現行のまま存在し機能していること
- 本変更はaide-powers自体のメタ開発であり、dev-environment.md §14 の定義に基づき、スキル定義・エージェント定義が設計書を兼ねること
