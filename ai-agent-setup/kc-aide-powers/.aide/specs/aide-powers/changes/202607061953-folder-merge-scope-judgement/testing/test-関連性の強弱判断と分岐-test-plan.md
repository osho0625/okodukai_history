## 試験項目1: 関連性「強い」と判断され根拠が明文化されること

- **確認項目**: ユーザーが、AIエージェントが起因元要件と統合先要件を比較し「関連性は強い」と判断した上で、その判断理由（根拠）を明文化して提示することを確認する
- **確認手順**:
  1. 起因元フォルダの要件内容と今回の作業内容が明確に関連する状況（例: 前回変更した機能に対する追加修正）でワークフローを起動する
  2. フォルダ統合判定に到達し、AIエージェントが提示する関連性の判断結果と根拠を確認する
- **確認環境**: aide-powersワークフロー実行環境上での確認、またはAIエージェントによるコードレビューでの確認
- **期待結果**: AIエージェントの提示内容に「関連性は強い」という判断結果と、その判断理由（起因元要件と統合先要件のどの部分がどのように関連しているかの具体的な根拠）が明文化されて表示されること

## 試験項目3: 判断困難時にAIが独自判断せずユーザーに確認すること

- **状態、条件**: 起因元フォルダの要件と今回の作業の要件の関連性が明確に強い・弱いと判断しづらい状態（例: 一部の観点では関連するが別の観点では無関係に見える）
- **確認項目**: ユーザーが、判断が難しい場合にAIエージェントが独自判断で確定せず、両方の可能性の根拠を提示した上で「1. 関連性は強い」「2. 関連性は弱い・なし」「3. その他（自由記述）」の3択でユーザーに確認を求めることを確認する
- **確認手順**:
  1. 起因元要件と統合先要件の関連性が判断しづらい状況を用意してワークフローを起動する
  2. フォルダ統合判定に到達したとき、AIエージェントが「判断に迷っている」旨と両方の可能性の根拠を提示するかを確認する
  3. 提示された選択肢が「1. 関連性は強い（統合検討へ進む）」「2. 関連性は弱い・なし（起因元なし扱いとする）」「3. その他（自由記述）」の3つであることを確認する
  4. いずれかの選択肢を選び、回答に応じて強弱が確定することを確認する
- **確認環境**: aide-powersワークフロー実行環境上での確認、またはAIエージェントによるコードレビューでの確認
- **期待結果**: AIエージェントが独自判断で強弱を確定せず、判断に迷っている旨・両方の可能性の根拠・3つの選択肢がユーザーに提示され、ユーザーの回答をもって強弱が確定すること
