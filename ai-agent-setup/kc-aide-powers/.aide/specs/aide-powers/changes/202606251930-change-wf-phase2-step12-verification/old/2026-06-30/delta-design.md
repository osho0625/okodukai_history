# 差分設計書

## 変更概要

実装WF（fs-impl-phase4-execution）で確立した動作確認の「4段階構造」（機能リスト作成→機能別試験書作成→試験実行→結果報告）を、残り3WF（変更/バグ修正/リファクタリング）に統一適用する。旧形式の冗長な⚠️注意書きブロックおよび verification-report.md（単一レポートファイル）を廃止し、testing/ 配下の機能リスト＋機能別試験書に移行する。

## 対応方針サマリー

- リファレンス: `skills/fs-impl-phase4-execution/SKILL.md` Step 2 / `skills/fs-impl-phase4-execution/impl-verification-prompt.md`
- WF間の差分: 実装WFは「全機能」が対象・出力先 `.aide/specs/{feature_name}/testing/`。他3WFは「実装箇所＋影響範囲にかかる機能」のみ対象・出力先は各作業フォルダ内 `testing/`
