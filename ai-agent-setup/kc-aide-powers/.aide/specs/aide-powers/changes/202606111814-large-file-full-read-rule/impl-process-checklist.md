> impl-task-planning スキルの「非プログラム成果物タスク（簡略サイクル）」を本変更の工程に合わせて拡張し、

> 各セルは「状態 / 実行エージェント名」の形式で記入する。

## セルの記号

| 記号 | 意味 |
|------|------|
| `[ ]` | 未実施 |
| `[x]` | 完了（PASS） |
| `[!]` | FAIL（修正中） |
| `[-]` | 該当なし（修正不要だった場合 / 当該工程が対象外） |

実行エージェント名は未実施時は `—`。実装・修正は micro-impl-agent、設計準拠レビューは design-review-agent を割り当てる（ホワイトリスト準拠）。

## 監査ルール（ホワイトリスト強制）

- 各セルには「状態 / 実行エージェント名」を記入する。
- 実装/修正の実行エージェント名は micro-impl-agent、設計準拠レビューは design-review-agent をホワイトリストとする。これら以外が記入された場合は ❌ FAIL 扱いとする。
- 検証（手動）はオーケストレータ／ユーザーによる手動確認工程であり、実行主体を明記する（自動テストは存在しない）。
- ホワイトリスト違反が検出された場合は、該当タスクの該当工程を正しいエージェントで再実行する。
