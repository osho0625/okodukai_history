## 変更方針の詳細
### 変更項目1: global-rules 正本への全行読み出しルール追記（REQ-C-001）
- **方針**: `skills/using-aide-powers/references/global-rules.md` に、ファイル読み出し時の全行取得を義務付ける恒久ルールを独立した見出し付きセクションとして新設する。記載趣旨は AC-002〜AC-004 を満たす次の要素を含める方針とする — (1) コード/ドキュメントは read_file で全行読む、(2) 部分ロード（"partially loaded"）・AST 要約モード時は start_line/end_line で分割し末尾まで全行取得する、(3) read_code 要約モード依存による読み落としを禁止する、(4) 適用対象は「コード/ドキュメントを読むあらゆる場面（恒久・汎用、全エージェント・全工程）」である、(5) 読み落としによる誤検出（false positive）・見逃し（false negative）を禁止する。文言は暫定先行実装（`.aide/task-plans/report-key-uniqueness/review-7-形式可読.md` 冒頭「読み出しルール（必須・最優先）」）を参考にする。
- **理由**: 読み落とし防止は全エージェント・全工程に共通する恒久課題（PI-032）であり、レビュー専用の局所対策ではなく正本への一元化が適切。既存のファイル読み取り関連ルールと同種であり、同一ファイル内で並べることで参照性・整合性が高まる。

### 配置方針（追記位置）
- **方針**: 新セクションは、ファイル読み取りの運用に関わる既存ルール群「ツールマップ参照ルール」「スキルの所在ルール」の直後（「実行環境ルール」との並びを考慮した位置）に配置する。これにより「ファイルをどう読むか」に関するルールが正本内で隣接してまとまる。
- **理由**: 既存の読み取り関連ルールと意味的に近く、読み手（全エージェント）が一連のファイル読み取り運用ルールとして把握しやすい。既存セクションの順序・文言は変更しない（追加のみ）。

### 変更項目2: version 更新と全プラットフォーム配布（REQ-C-002）
- **方針**: 正本追記の後、`skills/using-aide-powers/references/version.json` の version を 5→6 に更新し updated を更新する。続いて rules-distribute による全プラットフォーム配布、および `.aide/references/` への反映を実行し、配布先 global-rules（`.kiro/steering/aide-powers-global-rules.md` 等）に新ルールが再生成される状態とする。配布先ファイルの手動編集は行わない。
- **理由**: 正本追記のみでは AI 挙動に反映されない（前提条件・version.json の _comment）。version +1 が配布反映のトリガーであり、rules-distribute が正本から配布先を再生成する設計のため、手動編集ではなく version 更新＋配布実行が正規ルート。

## リファクタリング検討結果
- **検討結果**: 不要
- **理由**: 本変更は global-rules 正本への独立した新規セクションの追記と version 値の更新に限られ、既存ルールの文言変更・構造変更を伴わない（スコープ外で明示）。配布先は rules-distribute が正本から再生成する既存の仕組みをそのまま利用するため、拡張ポイントの新設や既存資産の再構成といったリファクタリングは発生しない。追加のみで OCP に整合しており、事前のリファクタリングは不要と判断する。
