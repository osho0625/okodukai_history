# バグ報告（PI-008）: compliance-sig.bat verify-phase の正規表現が成果物テーブルのハッシュを抽出できない

## 症状

verify-phase サブコマンドが進捗ファイルからフェーズセクションを抽出する際、成果物テーブルの SHA256 ハッシュ値を正しく抽出できない。結果として E3B0C44...（成果物なし固定値）が使用され、署名検証が失敗する。

## 根本原因

2つの正規表現に問題があった:
1. フェーズセクション抽出: `### フェーズN:` で始めていたが、`### フェーズN: 成果物` サブセクションが `### フェーズ` にマッチして切れてしまう
2. ハッシュ抽出: `\|\s*\S+\s*\|\s*([0-9a-fA-F]{64})\s*\|` は2列テーブル前提。3列テーブル（ファイル名|説明|SHA256）に対応できない

## 修正内容

1. フェーズセクション抽出を `## フェーズN:` から `<!-- PHASE-SIG:N:` までに変更
2. ハッシュ抽出を行末の64文字hex抽出に変更（列数に依存しない）

## テスト結果

- PI-001 bugfix-progress.md フェーズ1〜5: 全 PASS
- 変更WF change-progress.md フェーズ1（成果物なし）: PASS
- 変更WF change-progress.md フェーズ2（3列テーブル）: PASS
