# ツールマップ検証

## Overview

現在動作しているプラットフォームで、ツールマップに記載されたツールが実際に使用可能かを検証する。ツールマップファイルを Read で読み込み、そこに記載されたツール名を使って検証を実行する。

## 検証プロセス

### ステップ1: プラットフォーム特定とツールマップ読み込み

1. `using-aide-powers` (aide-powers skill) の `references/` 配下のツールマップファイル一覧を Glob で取得する
2. 各ツールマップファイルの冒頭（タイトル行）を Read で確認し、プラットフォーム名を把握する
3. 現在のプラットフォームを特定する方法:
   - Bash で `echo "platform-detect"` を実行し、使われたツール名から判定する
   - 例: `executePwsh` が呼ばれた → Kiro IDE、`shell` が呼ばれた → Kiro CLI
4. 対応するツールマップファイルを Read で全文読み込む

### ステップ2: ツールマップのパース

読み込んだツールマップから、以下の情報を抽出する:
- Claude Code ツール名 → プラットフォーム固有ツール名の対応表
- 「No equivalent」と記載されたツール
- プラットフォーム固有ツール一覧（Additional tools セクション）

### ステップ3: 実際のツール検証

ツールマップに記載された各ツールについて、**読み取り専用の最小操作**で呼び出し、使用可能かを確認する。

**検証するツール:**

| Claude Code名 | 検証方法 |
|---|---|
| Read | カレントディレクトリの任意ファイルを1行読む |
| Write | `.toolmap-verify-temp.md` を作成する（内容: `test`） |
| Edit | `.toolmap-verify-temp.md` の `test` を `verified` に置換する |
| Bash | `echo "toolmap-verify-test"` を実行 |
| Grep | カレントディレクトリで `"README"` を検索（結果不問） |
| Glob | `*.md` でファイル検索 |
| Skill | スキル一覧を確認する（呼び出し可能かの確認のみ） |
| Task | サブエージェントを起動し「検証成功」と返答させる |
| WebFetch | `https://example.com` を取得（truncated モード） |
| WebSearch | `"test"` で検索（1件取得） |
| TodoWrite | 存在しないタスクを更新してツール呼び出し可能かを確認する（エラーでもツール動作確認OK） |
| EnterPlanMode | ツールマップに「No equivalent」と記載されている場合、呼び出し不可であることを確認する |
| AskUserQuestion | ユーザーに「OK」と回答するよう質問する |
| LSP | 任意のシンボルを検索（結果不問） |
| Monitor | バックグラウンドプロセス一覧を取得する（起動はしない） |

**検証後のクリーンアップ:**
- Write/Edit の検証で作成した `.toolmap-verify-temp.md` を Bash で削除する
- 検証前後でワークスペースの状態が変わらないことを保証する

**スキップするツール:**
- なし（全ツールを検証する）

### ステップ4: プラットフォーム固有ツール検証

ツールマップの「Additional tools」セクションに記載されたツールのうち、読み取り専用で安全に検証できるものを試す。

### ステップ5: 照合とレポート

検証結果をツールマップの記載と照合し、以下の形式でレポートする:

```markdown
# ツールマップ検証レポート

## プラットフォーム
- 検出結果: {プラットフォーム名}
- ツールマップファイル: `using-aide-powers` スキル内 references/{platform}-tools.md

## カテゴリA ツール検証結果

| # | Claude Code名 | マップ記載のツール名 | 実際の状態 | 判定 |
|---|---|---|---|---|
| 1 | Read | {ツール名} | ✅ 使用可能 / ❌ 使用不可 | 整合 / 不整合 |
| ... | ... | ... | ... | ... |

## プラットフォーム固有ツール

| # | ツール名 | 実際の状態 | 備考 |
|---|---|---|---|
| ... | ... | ... | ... |

## 不整合一覧
（なければ「不整合なし ✅」）

## サマリ
- 検証: {N}件 / 使用可能: {N} / 使用不可: {N} / スキップ: {N} / 不整合: {N}
```

## 重要ルール

- **破壊的操作は絶対に行わない**（ファイル作成・変更・削除、プロセス起動、状態変更）
- 検証は読み取り専用の最小限の操作のみ
- エラーが発生したら「❌ 使用不可」として記録し、エラー内容も記載する
- ユーザーへの質問は行わない
- ツールマップに「No equivalent」と記載されたツールは検証をスキップする（使えないことが正しい）
