# テキサスホールデム ルールガイド

## 概要

テキサスホールデムのルール解説ページ。ゲームロジックは持たず、静的なルールリファレンスのみ。

## ファイル構成

- `pages/texas-holdem.html` — ルールガイドページ（単一HTMLファイルで完結）

## 機能

- タブ切り替えUI（基本ルール / 役の強さ / ハンド表 / ゲームの進め方 / ポジション / 用語集）
- 基本ルール（初心者向け: 目的・カードの使い方・ベットアクション・ゲームの流れ）
- 役の強さ一覧（10役、強い順、例・確率付き）
- プリフロップハンド強さ表（13×13マトリクス、Tier 1〜4の色分け）
- ディーラーの進め方（プリフロップ→フロップ→ターン→リバー→ショーダウン）
- ポジション解説（BTN/SB/BB/UTG/MP/CO）
- 用語集（基本アクション＋戦略用語）

## 技術仕様

- 外部JS/CSS依存なし（単一HTML完結）
- DB不使用
- 夜間制限非対応（ルール参照ページのため）
- common.js非読み込み（Supabase接続不要）
- ゲームセンターからのリンク対象外（ルール参照のみ）

## UI構成

- ヘッダー: ←(history.back) + タイトル + 🏠(index.html)
- タブナビ: 4タブ横並び
- コンテンツ: タブ切り替えで表示/非表示
- テーマ: ポーカーテーブル風グリーン基調
