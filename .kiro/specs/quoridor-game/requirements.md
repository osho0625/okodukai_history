# コリドール - 要件

## 概要
2人用戦略ボードゲーム。自分の駒を相手側の端に到達させたら勝ち。
壁を置いて相手の進路を妨害できるが、完全に塞いではいけない。

## 要件

### FR-1: ゲームルール
- 9×9ボード
- 各プレイヤーは10枚の壁を所持
- ターンで「駒移動（上下左右1マス）」か「壁配置（2マス分の壁）」
- 壁は相手の到達路を完全に塞いではならない（経路保証ルール）
- 自分の駒が相手側の端に到達したら勝利

### FR-2: プレイモード
- 2人対戦（同一端末パス&プレイ）

### FR-3: UI
- 9×9ボード + 壁溝の表示
- 駒のハイライト（移動可能先表示）
- 壁配置プレビュー
- 残り壁数表示

### FR-4: 制約
- 夜間制限対応
- DB不使用
- 単一HTMLファイルで完結
