# 神経衰弱 - 要件

## 概要
カードをめくって同じ絵柄のペアを見つける記憶力ゲーム。小学生向けのシンプルなルール。

## 要件

### FR-1: 難易度選択
- かんたん（6ペア = 12枚、4×3グリッド）
- ふつう（8ペア = 16枚、4×4グリッド）
- むずい（12ペア = 24枚、6×4グリッド）

### FR-2: ゲームルール
- カードは裏向きに配置
- ゲーム開始時に全カードを一瞬表示（記憶タイム: かんたん2秒/ふつう1.5秒/むずい1.2秒）
- 2枚めくって同じ絵柄ならペア成立（表のまま）
- 異なればカードを裏に戻す
- 全ペアを揃えたらクリア

### FR-3: UI表示
- ステータスバー: ペア数、タイマー、手数
- 3Dフリップアニメーション
- ペア成立時にスケールポップ演出
- クリア時にスコア評価（手数/ペア数の比率で5段階）

### FR-4: 操作性
- 不一致カード表示中にタップで早送り可能
- ペア判定中は入力ロック
- ゲーム中に「タイトルに戻る」ボタン（確認ダイアログ付き）
- ←/🏠ボタンにゲーム中断確認

### FR-5: 制約
- 夜間制限対応（isNightTime）
- DB不使用（ランキングなし）
- ねこ汚染スクリプト不要
