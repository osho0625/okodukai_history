# 国語・漢字 学習の進め方（かいせい・いろは・はるちか）

## 基本方針

国語は「問題をたくさん解く」のではなく、次の力を段階的に育てる。

- **読む力** — 文章を正確に読む
- **理解する力** — 文章や問いが何を言っているか分かる
- **根拠を探す力** — 答えの理由を文章中から見つける
- **書く力** — 自分の考えを言葉で表現する
- **漢字・語彙力** — 読める・書ける・意味が分かる・使える
- **考える力** — 読んだ内容から推測・比較・理由付けをする

いろは・はるちかでは **「なんとなく答える」から「文章を根拠にして答える」へ** を重要な目標とする。

かいせいは無理にドリルを増やさず、読書・会話・遊びで「言葉って面白い」という感覚を育てる。

---

## 最終目標

目指すのは「問題を解ける子」ではなく、**「文章を読んで、自分で考え、根拠を持って説明できる子」**。

そのために4つを連携させて育てる。

- 漢字 → 読める・書ける・意味が分かる
- 読解 → 正確に読む・根拠を探す
- 語彙 → 言葉の意味を理解する
- 記述 → 自分の言葉で説明する

## 漢字で身につけるもの

「書ける」だけを目標にせず、次の順番で身につける。

```
認識 → 読み → 意味 → 書き → 熟語 → 文中で使う
```

例：「必要」なら

- 「必要」を見て読める
- 意味が分かる
- 「必」「要」を正しく書ける
- 「必要」「必要性」などの言葉を知っている
- 「明日までに必要です」のように文中で理解できる

ここまでを目標とする。

## 学習サイクル

**練習 → 確認 → 間違い直し → 再テスト → 復習** のサイクルで使う。

### ① 練習
毎日長時間やらない。1回5〜10分が基本。「何ページやったか」より、集中して覚えられたかを重視する。

### ② 確認
一定範囲を終えたら覚えているか確認する。
- 新しく覚えた範囲：80%以上
- 復習テスト：90%以上

### ③ 間違い直し
ただ10回書かせるのではなく、原因を確認する（読み間違い／書き間違い／部首・形の間違い／熟語の意味が分からない／似た漢字との混同）。

### ④ 再テスト
間違えた漢字を数日後にもう一度確認する。一度正解しただけで「覚えた」と判断しない。

### ⑤ 間隔を空けて復習
覚えた漢字も、数日後・1〜2週間後・1か月後に再確認する。「忘れた頃に思い出す」ことを重視する。

## 漢字のテスト

ドリルだけで完結させず、定期的にランダムテストを行う。

- **毎週**：10〜20問。読み・書き・熟語・文中での使用を混ぜる
- **毎月**：その月に勉強した漢字をランダムに出題

目的は「順番ならできる」ではなく **「どこから出ても分かる」** 状態にすること。

## 語彙力

漢字だけでなく、言葉そのものを増やす。特に、似た意味／反対の意味／気持ちを表す／様子を表す／原因・結果を表す／時間・順序を表す言葉を意識する。

単語帳のように大量暗記させず、読書や読解問題で出会った言葉を中心に覚える。

## 読解の進め方

### STEP 1：正確に読む
流し読みせず、**誰が・いつ・どこで・何をした・なぜそうした** を意識して読む。

### STEP 2：問題文を正確に読む
解く前に「何を聞かれているのか」を確認する。「なぜ」「どんな気持ち」「どのような」「本文から抜き出しなさい」「自分の言葉で」などの指示を区別する。

### STEP 3：文章中から根拠を探す
感覚で決めず「その答えは文章のどこに書いてある？」を確認する。正解しても根拠を説明できなければ「読解力が身についた」とは考えない。

### STEP 4：間違いを分類する
答えを書き直すだけにせず、原因を分類する。

- A：読み間違い
- B：言葉の意味が分からなかった
- C：問題文の意味を取り違えた
- D：文章中の根拠を見つけられなかった
- E：根拠は分かったが、答え方が不適切だった
- F：文章から考えることができなかった

これにより「国語が苦手」という曖昧な状態にしない。

## 漢字と読解をつなげる

漢字と読解は別々に進めるが、完全に分離しない。

読解中に「意味が分からなかった言葉」が出たら、漢字・語彙の復習候補にする。「努力」「原因」「結果」「必要」など頻出の言葉は、漢字として覚えるだけでなく意味まで確認する。

```
漢字が読める
  ↓
言葉の意味が分かる
  ↓
文章が理解できる
```

というつながりを作る。

## かいせいの方針

### 今はドリルを無理にやらせない

まずは次の活動を中心にする。

- 絵本・児童書を読む／読み聞かせをする
- 日常会話を増やす
- 「どうして？」「どう思う？」と話す
- しりとり・言葉遊びをする
- 上の兄姉が勉強している姿を見る

**目標**：ひらがな・カタカナを自然に読める／短い文章を理解できる／自分の考えを言葉で説明できる／「なぜ？」を考える習慣／言葉に興味を持つ。

### 漢字

学校で習った漢字を中心に、読める・意味が分かる・少しずつ書けることを目標とする。

先取りを目的に大量のドリルはやらせない。「もっと勉強したい」と本人が思った時に始められる状態を優先する。

### 上の兄姉との関係

「お兄ちゃん・お姉ちゃんは勉強しているから自分もやらなきゃ」ではなく、**「やっているの、面白そう」** と思わせる。

- いろは・はるちかの学習を過度に邪魔しない
- かいせいにも問題を無理にやらせない
- 上の子が解く姿・「できた！」と楽しむ姿を見せる
- かいせいが興味を示したら簡単な問題を一緒にやってみる

## 家庭での学習時間（いろは・はるちか）

毎日長時間やらせることは目的にしない。

- 漢字：5〜10分
- 文章読解：10〜20分
- 読書：できる範囲で自由

毎日全部やる必要はない。疲れている日は漢字だけ・読書だけでもよい。

## 基本姿勢

- かいせいは無理にドリルをさせない
- いろは・はるちかは同じ基本方針で進める
- 漢字は「漢字力MAXドリル」を軸にする

- 正解数だけでなく「なぜその答えなのか」を重視する
- 間違いを責めず「どこで間違えたか」を分析する
- 難易度は理解度に合わせて段階的に上げる
- 勉強量より、自分で考えて理解することを優先する
