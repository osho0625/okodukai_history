# 🔌 micro:bitでうごくものをつくろう！

これは、はるちかがmicro:bit（マイクロビット）と「シャミ拡張ボード」で、光る・音が鳴る・動くものを作るためのガイドだよ。
答えは書いてない。ヒントだけ読んで、自分で考えて作ってみよう！

Scratchと同じで、**ブロックをならべて**プログラムを作るよ。Scratchでやったことが、そのまま使える！
ちがうのは、画面の中だけじゃなくて、**本物の光やモーターが動く**こと。

わからなくなったら、下の「べんりなリンク」を見てみよう。
それでもわからなかったら、パパに「ここまではできたんだけど」って見せてね。

**▼をタップして、各ステップを開いてはじめよう！**

---

<details>
<summary>🌟 はじめに：micro:bitってなに？（⏱️ 5分）</summary>

micro:bitは、クレジットカードの半分くらいの小さなコンピューターだよ。
**LEDの画面（5×5）**、**ボタン**、**マイク**、**スピーカー**、**かたむきセンサー**などが、はじめから付いているよ。

**拡張ボード（シャミ）** はmicro:bitをさしこんで使う、おまけの基板。
信号機のライト、温度・湿度センサー、小さい画面（OLED）、モーターをつなぐ場所などがあるよ。

**これからやること：** パソコンでプログラムを作る → USBケーブルでmicro:bitに送る → 動く！

</details>

<details>
<summary>🔧 準備：プログラムを作る場所を開こう（⏱️ 15分）</summary>

1. パソコンで https://makecode.microbit.org/ をひらく
2. 「新しいプロジェクト」をおして、名前をつける
3. 画面のようすをしらべよう（Scratchとにているよ！）

| 場所 | なにがあるか |
|------|------------|
| 左がわ | ブロック置き場 |
| 真ん中 | コードエリア（ここにブロックをならべる） |
| 左上 | シミュレーター（本物がなくても、画面で動きをためせる） |
| 右下 | 「ダウンロード」ボタン |

**micro:bitにプログラムを送るには：**
1. USBケーブルでmicro:bitとパソコンをつなぐ
2. 「ダウンロード」をおす
3. 「MICROBIT」というドライブにファイルをいれる（ドラッグ）

（ヒント：できないときは、パパにケーブルのつなぎ方を見てもらおう）

</details>

1. micro:bitを **ふったら** 何か表示するには？（「入力」カテゴリを見てみよう）
2. **温度** を表示するには？（micro:bitには温度センサーがあるよ）
3. **サイコロ** を作るには？（「計算」カテゴリに、ランダムなブロックがあるよ）

<details>
<summary>🔥 ステップ5：火災警報器を作ろう（⏱️ 1時間・パパといっしょに！）</summary>

### ⚠️ やくそく

**これは、かならずパパといっしょにやること！** 火を使うので、ひとりでやらない。
火を使うときは、まわりに燃えるものがないか、水が近くにあるか、確かめよう。

### ゴール

火を見つけたら、**画面に数字が出て、音が鳴って、ライトが赤くなる** 警報器を作ろう！

### 考えること

1. 火のセンサーの **強さ** を、画面に出すには？
2. 強さが **ある数字をこえたら** 警報を出すには？
3. 警報は **音** と **赤いライト** の両方を出そう
4. 火が消えたら、警報も **止まる** ようにするには？

### ヒント

- まずは数字を画面に出してみて、火が近づくとどう変わるか見よう（センサーから20cmくらいはなして試す）
- 「もし〜なら」ブロックの「〜」の中に、数字をくらべるブロックを入れよう
- 数字は、実験して決めよう。ふだんは何くらい？ 火を近づけたら何くらい？
- 音を鳴らすブロックは「音楽」カテゴリにあるよ

### 🎉 完成チェック

- [ ] パパと一緒に準備した
- [ ] 火の強さが画面に出る
- [ ] 火を近づけると、音が鳴ってライトが赤くなる
- [ ] 火が消えると、警報も止まる

</details>

<summary>📡 ステップ6：リモコンでスイッチを入れよう（⏱️ 2時間・ひつようなものあり）</summary>

### ひつようなもの

- 赤外線リモコン（テレビのリモコンとはちがうものが必要になることがあるよ。パパに聞いてね）

### ゴール

リモコンのボタンで、拡張ボードの **スイッチ（リレー）** をON/OFFしよう！

### 考えること

1. リモコンの **どのボタンをおしたか** を知るには？
2. **「1」をおしたらON、「0」をおしたらOFF** にするには？
3. ONのときは **「✓」**、OFFのときは **「×」** をmicro:bitに出そう
4. ライトも **青（ON）/赤（OFF）** にしてみよう

### ヒント

- ボタンごとに、番号（整数）が決まっているよ。まずはボタンをおして、番号を画面に出してみよう
- 「もし〜なら」で、どのボタンかを区別しよう
- リレーは「パチッ」という音がするよ。耳をすませよう

### 🎉 完成チェック

- [ ] リモコンのボタンの番号が分かった
- [ ] 「1」でON、「0」でOFFになる
- [ ] ONのとき、リレーがパチッと鳴った

### 💪 もっとよくするアイデア

- 本物の電気（ランプなど）をつなぐのは、**かならずパパに相談して、パパにやってもらおう**（家のコンセントの電気は、リレーに直接つながない）
- 植物の水やりポンプを作る（電池式の小さなものを使う）

<details>
<summary>🏆 ステップ8：オリジナル作品を作ろう（⏱️ 2週間）</summary>

### ゴール

ステップ0〜7で学んだことを組み合わせて、**自分で考えたもの** を企画書から作ろう！

### やること

Scratchのステップ5と同じように、まず「企画書」を書こう。いきなり作り始めない！

### 企画書に書くこと

1. **作品名** — かっこいい名前をつけよう
2. **どんなもの？** — ひとことで説明できる？（例：「あつくなったら教えてくれる、おうちの温度見はり番」）
3. **使うもの** — ライト？ 画面？ センサー？ モーター？
4. **どうなったら成功？** — 完成の決め手は何？
5. **むずかしそうなところ** — どこで困りそう？

### アイデアの例

- 部屋の **温度・湿度見はり番**（暑すぎたら、光って教える）
- **おうちの信号機**（ゴミ出しの日だけ青に光る）
- **リモコンで動くロボット**
- **火事を見つけて教える**警報器
- **ボタンをおすと、ランダムでじゃんけんの手を出す**マシン

### 進め方

1. 企画書を書く
2. パパに見せる
3. 一番かんたんな部分から作る
4. 少し作ったらテスト。動いたら次を足す
5. 完成したらパパに見てもらう

### こんなとき

- **むずかしくなった** → 企画書を見直そう。シンプルにできる部分はない？
- **思ったとおりに動かない** → ブロックを1つずつ確認しよう。シミュレーターでためすのもいいよ
- **飽きた** → 一回休んで、次のアイデアを書いてみよう

### 🎉 完成チェック

- [ ] 企画書を書いた
- [ ] パパに企画書を見せた
- [ ] 作り始めた
- [ ] 完成して、人に見せた

</details>

<details>
<summary>👨‍👩‍👧 パパへ（保護者向けメモ）</summary>

### 進め方の方針

- ガイドはScratchと同じで、**答えを書かず、ヒントだけ**にしている。
- つまづいたときは、「どこまでできた？」と聞いて、本人に説明させる。説明するだけで自力で気づくことも多い。
- 迷ったときの最後の手段が、**日本語マニュアルやWikiのサンプル**（完成プログラムが見られる）。「ずるくない」と伝えてある。

### 親が手伝うポイント

| ステップ | 親の関与 |
|---|---|
| 準備・ステップ1 | micro:bitをボードにさす向き、USBの接続を一緒に確認 |
| ステップ5（火災警報器） | **必ず同席。** ライターの火を使うため |
| ステップ6（リモコン） | リモコンの用意。家庭用電源（コンセント）につなぐのは親がやる |
| ステップ7（モーター） | 外部電源の極性（プラスマイナス）を確認。まちがえるとボードが壊れる |

### 追加購入が必要なもの（ステップ6以降）

- 赤外線リモコン（iftinyの日本語マニュアルでは、同ストアのリモコンを例に使用）
- モーター、外部電源（電池ホルダー、5〜12V、DC2.1プラグ）
- サーボ（180度）：つまみでの角度調整に使う（このガイドでは扱っていない）
- SR04超音波センサー：距離測定に使う（このガイドでは扱っていない）

### 注意

- iftinyマニュアルのサンプルは、MakeCodeライブラリ **v0.7.0** 時点の内容。最新版ではブロックの名前や手順が変わっていることがある。
- ガイドのブロック名は、拡張機能を入れたあとの実画面で確認すること（本ガイドには書いていない）。

</details>
