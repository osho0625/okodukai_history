## 方針

- 屋内（客間）に床置き型を常設

- 予算：1万円前後

## 各製品レビュー

### BARWING ぶら下がり健康器

**良い点：**
- 約8,000円で多機能。コスパ最強クラス
- 4WAY懸垂バーでグリップの自由度が高い
- 3Dパッド搭載で背面サポートあり（レッグレイズがやりやすい）
- 高さ調整8段階。173cmなら問題なし
- Amazon「ベストセラー」常連。購入者300+/月
- 1台で懸垂・ディップス・レッグレイズ・腕立て伏せに対応

**気になる点：**
- 一部レビューで「懸垂時にチンニングバーグリップが回転する」報告あり（改良モデルで対策済みとの情報も）
- 組み立て30〜40分。説明書がやや分かりにくいとの声
- 保証の明記がない（販売元YouTenに問い合わせ）

**総評：** 予算1万円以内で最も選ばれている定番。初めての懸垂マシンとして間違いない。

### STEADY ST115

**良い点：**
- 1年保証付き。日本企業（STEADY）が運営
- 特許庁実用新案取得済み
- マット付属で床を傷つけない（客間設置に◎）
- 省スペース設計で口コミでも「コンパクト」の評価多数
- 高さ10段階調整
- ウエストパッド＋アームパッドでレッグレイズが快適
- 楽天レビュー「安定性とコンパクトさを高く評価」

**気になる点：**
- 約12,000円でBARWINGより4,000円高い
- 一部レビューで「揺れる」「きしみ音」報告（個体差の可能性）
- 組み立てに40〜60分

**総評：** 保証・品質・サポートを重視するならこれ。日本企業の安心感。BARWINGとの差額4,000円を「保証＋マット＋安心」と考えるなら妥当。

### LEADING EDGE LE-CS200

**良い点：**
- 楽天1位獲得実績あり
- フレームがしっかりしている（口コミで安定性高評価）
- アシスト付きモデルもあり（懸垂0回からスタートできる）
- 高さ8〜10段階調整
- トレーニング専門ブランドとしての信頼

**気になる点：**
- 約11,800円。BARWINGと比べて機能差が小さい割に高め
- 耐荷重120kgでやや低い（61kgなら余裕だが将来的にウエイトベスト追加時は注意）
- Amazon発売予定日が2026年7月（新モデル切り替え中？）

**総評：** 品質・ブランドの信頼度は高いが、BARWINGやSTEADYと比べて飛び抜けた優位性が見えにくい。

### WASAI MK301 / BS502

**良い点：**
- Amazon ★4.3（3,243件）で圧倒的レビュー数
- 意匠登録取得済み（デザイン保護）
- 耐荷重150kg
- 4グリップ対応でワイド・ナロー切り替えやすい
- コンパクト設計の評価が高い
- 約7,000〜9,000円で安い

**気になる点：**
- サクラチェッカーでレビューの信頼性にやや疑問との指摘あり
- 背面パッドが薄めとの口コミ
- 組み立て説明書が簡素

**総評：** レビュー数・価格ともに魅力的。BARWINGと同価格帯のライバル。実績はあるが、サクラレビューの指摘が気になる人はSTEADYやBARWINGの方が安心。

### WellDay（ドア枠タイプ）

**良い点：**
- 約3,400円で最安
- 省スペースで見た目スッキリ
- 設置が最も簡単

**気になる点：**
- ワイドグリップが取れない
- ドア枠の強度に完全依存（枠が弱いと危険）
- ディップス・レッグレイズ不可
- 懸垂時の安心感が床置きに比べ劣る

**総評：** 「省スペース最優先で懸垂だけできればいい」場合のみ。9か月計画で種目を増やしていくなら床置きの方が良い。

## 結論・おすすめ

**客間に常設するなら BARWING か STEADY ST115 の二択。**

| 重視すること | おすすめ |

| コスパ最優先 | BARWING（約8,000円） |
| 保証・品質・マット付き重視 | STEADY ST115（約12,000円） |
| レビュー実績重視 | WASAI（約7,000〜9,000円） |
| 省スペース最優先 | WellDay（約3,400円） |

個人的にはBARWINGで十分。4,000円追加で保証とマットが欲しいならSTEADY。
