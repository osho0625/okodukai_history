## 2. 観光のポイント

### 箱根ロープウェイ
- 大きな窓のゴンドラで空中散歩。晴れていれば**富士山・芦ノ湖・大涌谷の噴煙**が一度に見えます
- 富士山は大涌谷〜桃源台の区間で見えやすく、雲が少ない**午前中がおすすめ**
- 乗り物好きの子どもに人気。進行方向の窓側を子どもに譲ってあげると喜びます

### 大涌谷
- 約3,000年前の火山活動でできた噴煙地帯。白い噴気と硫黄のにおいで「火山の上にいる」実感があります
- 2025年春に駅前広場が「ちきゅうの谷」としてリニューアル。展望スポットは3か所あります
  - **息吹のデッキ**：ガラス越しに足元の噴気を間近で見られる
  - **風の輪テラス**：360度の展望。晴れていれば富士山も
  - **大空のほとり**：目の前をロープウェイが通る
- 奥の「自然研究路」は**事前のオンライン予約制（1人800円）**で、足元が悪い道です。今回は展望エリアだけで十分楽しめます

### 箱根海賊船
- 海賊船の形をした遊覧船。乗るだけで子どもが盛り上がります
- 外のデッキに出ると、湖面・周りの山・富士山がよく見えます
- 元箱根港に近づくと、**湖の上に建つ平和の鳥居**が船から見えます。写真のチャンスです
- 行きは箱根町港にも寄りますが、降りずにそのまま元箱根港まで乗ります

#### 行きは特別船室（First Class）に乗る
通常の運賃（今回は乗り放題パス）に、追加料金を払って利用できる上位クラスの船室です。

| 項目 | 内容 |
|---|---|
| 追加料金（片道） | 桃源台港〜箱根町港・元箱根港：大人800円／小学生400円 |
| 乗り放題パスの優待 | パスを持っていると片道100円引き（小学生は50円引き）→ 大人700円／小学生350円 |
| 7名分の目安 | 大人700円×4＋小学生350円×3＝**3,850円**（優待なしなら4,400円） |
| 特典 | 豪華な内装の専用船室、**専用の展望デッキ**、ウォーターサーバー、船内アテンダント（写真撮影の手伝い・観光案内）、記念のオリジナルリストバンド、**優先乗船** |
| 購入方法 | **乗船する港の窓口でのみ当日販売**。予約・オンライン購入は不可 |
| 対象の船 | 3隻（クイーン芦ノ湖・ロワイヤルⅡ・ビクトリー）すべてに設置 |

- 日曜は売り切れる可能性もあるため、ロープウェイで桃源台に戻ったら**すぐに窓口で購入**します
- 優待の金額・定員・箱根町港を過ぎても特別船室に乗り続けられるかは、公式サイトで確認しきれていません。購入時に窓口で「元箱根港まで」と伝えて確認してください
- 混雑した普通船室と分かれているので、祖父も座ってゆっくり過ごせます。子どもはリストバンドと専用デッキで喜びます
- [公式：特別船室](https://www.hakonenavi.jp/hakone-kankosen/firstclass/)

### 元箱根・箱根神社
- 奈良時代（757年）創建と伝わる歴史ある神社。源頼朝など武将にも信仰されました
- **平和の鳥居**：芦ノ湖の湖上に建つ朱色の鳥居。湖面に映る「逆さ鳥居」がきれいです。週末は撮影待ちの列ができるので、長ければ列の横から撮るのがおすすめ
- **九頭龍神社新宮**：箱根神社の境内にあり、縁結びの神様として人気
- 本殿までは石段があります。祖父がきつそうなら、鳥居周辺の湖畔だけでも雰囲気を楽しめます

### 仙石原すすき草原
- 台ヶ岳の斜面一面に広がるすすきの草原。「かながわの景勝50選」にも選ばれています
- 10月13日時点で黄金色に色づいているとの情報あり。**当日はちょうど見頃**です
- 草原の中の一本道を往復できます。ゆるい上り坂があるので、祖父は途中で引き返してもOK
- 駐車場：9〜11月は無料の臨時駐車場が開設されます（草原に近い第2臨時駐車場が便利）。ほかに有料駐車場もあり

## 6. 注意点

### 体調・服装
- **大涌谷の火山ガス**：ぜんそく・気管支・心臓に持病がある方は注意が呼びかけられています。祖父に持病があれば、桃源台駅で休む、またはロープウェイから景色を見るだけにする
- **寒さ**：大涌谷は標高約1,000mで、夕方は10℃前後まで下がることも。全員に上着（フリース等）を
- **車酔い**：芦ノ湖周辺はカーブの多い山道。子どもは酔い止めを
- **海賊船のデッキ**：風が強いので帽子が飛ばされないように

### チケット・駐車場
- 乗り放題パスがお得：大人5,000円×4＋小学生1,400円×3＝**24,200円**（個別に買うと30,900円で、約6,700円の差）。日曜は窓口が混むので、代表者がまとめて購入
- 駐車場：桃源台駅駐車場・湖尻林間駐車場は1回1,000円（車2台なら2台分）
- [公式：海賊船・ロープウェイ乗り放題パス](https://www.hakonenavi.jp/transportation/ticket/ship_ropeway/)

### 運休・乗り遅れたとき
- **ロープウェイが運休**（強風・火山ガス）：車で大涌谷駐車場（有料・週末は大変混雑）へ行くか、すすき草原・箱根ガラスの森に切り替え
- **海賊船の帰りの便に乗り遅れた**：次の便を待つか、元箱根港の7番のりばから箱根登山バス**H路線「桃源台・東名御殿場行き」**で桃源台へ戻る
- **間違えて箱根町港で降りた**：桃源台へ直接戻れるバスかを乗り場で確認。なければ乗り継ぎまたはタクシー（7名なら2台必要）
