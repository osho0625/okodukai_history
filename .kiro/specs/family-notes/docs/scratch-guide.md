# 🎮 Scratchでゲームをつくろう！

これは、はるちかがScratch（スクラッチ）でゲームを作るためのガイドだよ。
順番にやっていけば、だんだんすごいゲームが作れるようになる！

---

## 🌟 はじめに：Scratchってなに？

Scratchは、ブロックを組み合わせてゲームやアニメーションを作れるツールだよ。
文字を打つプログラミングとちがって、ブロックをドラッグ＆ドロップするだけ！

**Scratchのサイト：** https://scratch.mit.edu/

---

## 🔧 準備：アカウントをつくろう

1. https://scratch.mit.edu/join をひらく
2. ユーザー名を決める（本名はつかわない！ニックネームにしよう）
3. パスワードを決める（パパに伝えておこう）
4. パパのメールアドレスを入れる
5. 「アカウントを作成」をおす

これで作った作品を保存できるようになるよ！

---

## 📝 Scratchの画面の見かた

Scratchエディタ（https://scratch.mit.edu/projects/editor/）をひらくと：

| 場所 | なにがあるか |
|------|------------|
| 左がわ | ブロック置き場（ここからブロックを選ぶ） |
| 真ん中 | コードエリア（ここにブロックを並べる） |
| 右上 | ステージ（ゲームが動く画面） |
| 右下 | スプライト一覧（キャラクターの管理） |

**スプライト** = ゲームに出てくるキャラクターやもの
**ステージ** = ゲームの背景（はいけい）
**コスチューム** = スプライトの見た目

## 🐱 ステップ0：まずはネコを動かしてみよう（10分）

はじめてScratchをさわるなら、まずこれをやろう！

### やること

1. Scratchエディタをひらく
2. 最初からいるネコのスプライトをクリック
3. 左の「イベント」カテゴリから `🏁 旗がクリックされたとき` をドラッグして真ん中に置く
4. 「動き」カテゴリから `10歩動かす` をドラッグして、旗ブロックの下にくっつける
5. 右上の 🏁（みどりの旗）をクリック！

→ ネコが少し右に動いたらOK！

### チャレンジ

- 「10歩」を「100歩」に変えてみよう。もっと動く？
- 「制御」カテゴリの `ずっと` ブロックで囲んでみよう。ネコが止まらなくなる！
- 「動き」の `もし端についたら、跳ね返る` を入れてみよう

## 🏰 ステップ1：迷路ゲームをつくろう

ゴール：矢印キーでキャラを動かして、壁にぶつからずにゴールまでたどりつくゲーム！

### パート1：迷路の背景をかく

1. 右下の **ステージ** をクリック
2. 「背景」タブをクリック
3. 左下のふでマーク（🖌️描く）をクリック
4. こうやってかく：
   - **塗りつぶし**ツールで全体を **白** にする
   - **四角形**ツールか**線**ツールで、**黒い壁**をかく
   - 迷路の入口（スタート）と出口（ゴール）をあけておく
5. ゴール地点に **赤い丸** をかく（ゴール判定に使う）

**💡 コツ：** 最初はかんたんな迷路にしよう！壁は太めにかくと判定がやりやすいよ。

### パート2：キャラを小さくする

1. スプライト一覧のネコをクリック
2. 「大きさ」を **30** くらいにする（迷路の道に入るサイズ）
3. ネコをスタート地点にドラッグして置く

### パート3：矢印キーで動かすコード

ネコのスプライトを選んで、このコードを作ろう：

```
🏁 旗がクリックされたとき
ずっと
  もし <上向き矢印▲ キーが押された> なら
    y座標を 5 ずつ変える
  end
  もし <下向き矢印▼ キーが押された> なら
    y座標を -5 ずつ変える
  end
  もし <右向き矢印▶ キーが押された> なら
    x座標を 5 ずつ変える
  end
  もし <左向き矢印◀ キーが押された> なら
    x座標を -5 ずつ変える
  end
end
```

**ブロックの見つけかた：**
- `🏁 旗がクリックされたとき` → 「イベント」カテゴリ（黄色）
- `ずっと` → 「制御」カテゴリ（オレンジ）
- `もし〜なら` → 「制御」カテゴリ（オレンジ）
- `〇〇キーが押された` → 「調べる」カテゴリ（水色）
- `y座標を〇ずつ変える` → 「動き」カテゴリ（青）

### パート4：壁にぶつかったらもどる

スタート地点の座標をメモしておこう（ネコを置いた場所のx, yが右に表示される）。

追加するコード（ずっとの中に入れる）：

```
もし <色 ■黒 に触れた> なら
  x座標を (スタートのx) にする
  y座標を (スタートのy) にする
end
```

**ブロックの見つけかた：**
- `色〇に触れた` → 「調べる」カテゴリ → 色の四角をクリック → スポイトで背景の黒い壁をクリック！

### パート5：ゴールしたらクリア！

追加するコード（ずっとの中に入れる）：

```
もし <色 ■赤 に触れた> なら
  「ゴール！おめでとう！」と 2 秒言う
  すべてを止める
end
```

### 🎉 完成！テストしよう

🏁をクリックして遊んでみよう。
- 矢印キーで動く？
- 壁にぶつかるとスタートにもどる？
- ゴールの赤に触れたらクリアって出る？

### 💪 もっとよくするアイデア

- タイマーをつけてクリアタイムを表示する（「変数」→「タイマー」）
- ステージを2つ作って、ゴールしたら次の迷路に進む
- 動く障害物（てき）を追加する

## 🚪 ステップ2：脱出ゲームをつくろう

ゴール：部屋にあるアイテムを見つけて、ドアを開けて次の部屋にすすむゲーム！

### パート1：部屋（背景）を用意する

1. ステージを選んで「背景」タブ
2. 背景を3つ作る（3つの部屋）：
   - **部屋1：** へや全体を描く。ドア（茶色い四角）を右に描く
   - **部屋2：** ちがう部屋。ドアを右に描く
   - **部屋3：** 最後の部屋。「脱出成功！」と書く
3. 背景の名前を「部屋1」「部屋2」「クリア」にしておく

### パート2：アイテム（鍵）をつくる

1. スプライト一覧の右下 🐱＋マークから「スプライトを選ぶ」
2. 「Key」で検索して鍵のスプライトを追加（なければ自分で描く）
3. 鍵を部屋1のどこかに置く

### パート3：変数を作る

1. 「変数」カテゴリをクリック
2. 「変数を作る」をクリック
3. 名前を「鍵」にする
4. 「すべてのスプライト用」を選んでOK

### パート4：鍵のコード

鍵スプライトのコード：

```
🏁 旗がクリックされたとき
鍵 を 0 にする
表示する

ずっと
  もし <マウスのポインター▼ に触れた> かつ <マウスが押された> なら
    鍵 を 1 にする
    「鍵をゲット！」と 1 秒言う
    隠す
  end
end
```

**ポイント：**
- `鍵を0にする` → 最初は鍵を持ってない状態
- `鍵を1にする` → 鍵をゲットした！
- `隠す` → 画面から消える

### パート5：ドアのコード

1. ドアのスプライトを作る（四角い茶色の絵でOK）
2. 部屋1のドアの場所に置く

ドアスプライトのコード：

```
🏁 旗がクリックされたとき

ずっと
  もし <マウスのポインター▼ に触れた> かつ <マウスが押された> なら
    もし <鍵 = 1> なら
      「ドアが開いた！」と 1 秒言う
      背景を 部屋2▼ にする
      メッセージ1▼ を送る
    でなければ
      「鍵がないと開かない…」と 2 秒言う
    end
  end
end
```

**「メッセージを送る」のしくみ：**
- 「イベント」カテゴリの `メッセージ1を送る` ブロック
- これを使うと、他のスプライトに「次のステージだよ！」と教えられる
- 新しいメッセージを作って「次の部屋」という名前にしてもOK

### パート6：プレイヤーキャラ

プレイヤーのスプライトを追加して、矢印キー移動のコードをつける（迷路ゲームと同じ）。

### パート7：部屋2の鍵とドア

- 部屋2用の鍵スプライトをもう1つ作る
- 部屋2のドアをもう1つ作る（触れたら背景を「クリア」にする）
- 「メッセージ1を受け取ったとき」で部屋2用のスプライトを表示する

```
メッセージ1▼ を受け取ったとき
表示する
```

### 🎉 完成チェック

- 鍵をクリックするとゲットできる？
- 鍵なしでドアを触るとメッセージが出る？
- 鍵ありでドアを触ると次の部屋に行く？
- 最後の部屋でクリア画面が出る？

### 💪 もっとよくするアイデア

- パスワード入力（「答えと聞いて待つ」ブロック）
- 暗号を解くなぞなぞ
- 制限時間
- 隠しアイテム

## 🚀 ステップ3：シューティングゲームをつくろう

ゴール：自分の宇宙船を左右に動かして、弾を撃って敵をたおすゲーム！

### パート1：自機（じき）をつくる

1. ネコを削除（右クリック→削除）
2. 新しいスプライトを追加（「Rocketship」や好きな乗り物）
3. 画面の下のほうに置く
4. 大きさを **50** くらいにする

自機のコード：

```
🏁 旗がクリックされたとき
y座標を -150 にする
ずっと
  もし <右向き矢印▶ キーが押された> なら
    x座標を 7 ずつ変える
  end
  もし <左向き矢印◀ キーが押された> なら
    x座標を -7 ずつ変える
  end
end
```

### パート2：弾をつくる

1. 新しいスプライトを描く（小さい黄色い丸でOK）
2. 名前を「弾」にする
3. 大きさを **20** にする

弾のコード：

```
🏁 旗がクリックされたとき
隠す

ずっと
  もし <スペース▼ キーが押された> なら
    自分自身▼ のクローンを作る
    0.3 秒待つ
  end
end

クローンされたとき
Rocketship▼ へ行く
表示する
y座標を 10 ずつ変える を繰り返す（ずっと）
  もし <端に触れた> なら
    このクローンを削除する
  end
end
```

**🔑 クローンってなに？**
- 「クローン」＝コピーを作ること
- 弾は何発も撃つから、コピーをどんどん作る
- 元の弾は `隠す` で見えなくして、クローンだけが画面に飛んでいく
- `クローンされたとき` は、コピーが生まれた瞬間に動くコード

**ブロックの場所：**
- `自分自身のクローンを作る` → 「制御」カテゴリ
- `クローンされたとき` → 「制御」カテゴリ
- `このクローンを削除する` → 「制御」カテゴリ

### パート3：てき（敵）をつくる

1. 新しいスプライトを追加（「Crab」や「Ghost」など）
2. 名前を「敵」にする
3. 大きさを **40** にする

敵のコード：

```
🏁 旗がクリックされたとき
隠す

ずっと
  1〜2 秒待つ
  自分自身▼ のクローンを作る
end

クローンされたとき
x座標を (-200 から 200 までの乱数) にする
y座標を 180 にする
表示する
ずっと
  y座標を -3 ずつ変える
  もし <y座標 < -180> なら
    このクローンを削除する
  end
end
```

**ポイント：**
- 敵は上からランダムな位置に出てくる
- `乱数` は「演算」カテゴリ（緑）にある
- 画面の下まで来たら消える

### パート4：当たり判定とスコア

1. 「変数」カテゴリで「スコア」という変数を作る

敵のコードに追加（「ずっと」の中）：

```
もし <弾▼ に触れた> なら
  スコア を 1 ずつ変える
  このクローンを削除する
end
```

### パート5：ゲームオーバー

自機のコードに追加（「ずっと」の中）：

```
もし <敵▼ に触れた> なら
  「ゲームオーバー！」と 2 秒言う
  すべてを止める
end
```

### 🎉 完成チェック

- 自機が左右に動く？
- スペースキーで弾が上に飛ぶ？
- 敵が上からランダムに落ちてくる？
- 弾が敵に当たるとスコアが増える？
- 敵が自機に当たるとゲームオーバー？

### 💪 もっとよくするアイデア

- 敵の種類を増やす（速い敵、ジグザグに動く敵）
- パワーアップアイテム（弾が大きくなる、連射できる）
- ボス戦（HPのある大きな敵）
- BGMと効果音をつける（「音」タブ）

## 🦘 ステップ4：アクションゲームをつくろう

ゴール：ジャンプして足場をのぼっていくゲーム！（マリオみたいなやつ）

### パート1：重力を作る

**重力ってなに？**
現実の世界では、ものは下に落ちるよね。ゲームでもそれを再現する！
「y速度」という変数を使って、キャラが常に落ちるようにするよ。

1. 「変数を作る」→「y速度」（このスプライトのみ）
2. 「変数を作る」→「地面についてる」（このスプライトのみ）

プレイヤーのコード：

```
🏁 旗がクリックされたとき
x座標を -180 にする
y座標を -100 にする
y速度 を 0 にする

ずっと
  ── 重力（下に引っぱる） ──
  y速度 を -1 ずつ変える
  y座標を (y速度) ずつ変える

  ── 地面（緑色）に触れたら止まる ──
  もし <色 ■緑 に触れた> なら
    y速度 を 0 にする
    地面についてる を 1 にする
    ── 地面にめりこまないように上に戻す ──
    「色■緑に触れた」でなくなるまで繰り返す
      y座標を 1 ずつ変える
    end
  でなければ
    地面についてる を 0 にする
  end

  ── 左右移動 ──
  もし <右向き矢印▶ キーが押された> なら
    x座標を 5 ずつ変える
  end
  もし <左向き矢印◀ キーが押された> なら
    x座標を -5 ずつ変える
  end

  ── ジャンプ ──
  もし <スペース▼ キーが押された> かつ <地面についてる = 1> なら
    y速度 を 12 にする
  end
end
```

**重力のしくみ：**
- `y速度` が毎フレーム -1 される → だんだん速く落ちる
- 地面に触れたら `y速度` を 0 にする → 落下が止まる
- ジャンプ＝ `y速度` を +12 にする → 上に飛ぶ → 重力でだんだん落ちてくる

### パート2：ステージ（地面と足場）をかく

1. ステージ（背景）を選ぶ
2. 背景を描く：
   - 画面の下に **緑色の長い四角**（地面）
   - その上に **緑色の短い四角** をいくつか（足場）
   - 好きな場所にゴール（赤い旗とか）を描く

**💡 重要：** 地面と足場は **同じ緑色** で描くこと！「色に触れた」で判定するから。

### パート3：敵（トゲ）をつくる

1. 新しいスプライトを描く（赤いトゲトゲ）
2. 足場のあいだに置く

プレイヤーのコード追加（「ずっと」の中）：

```
もし <トゲ▼ に触れた> なら
  x座標を -180 にする
  y座標を -100 にする
  y速度 を 0 にする
end
```

→ トゲに当たるとスタートにもどる！

### パート4：ゴール

```
もし <色 ■赤 に触れた> なら
  「クリア！おめでとう！」と 2 秒言う
  すべてを止める
end
```

### 🎉 完成チェック

- キャラが下に落ちる（重力がきいてる）？
- 地面や足場の上に立てる？
- スペースでジャンプできる？
- 空中でジャンプできない（二段ジャンプしない）？
- トゲに当たるとスタートにもどる？
- ゴールでクリア？

### 💪 もっとよくするアイデア

- 動く足場（x座標を行ったり来たりさせる）
- コインを集める（スコア表示）
- ステージ2、3を作る（背景切り替え）
- 壁ジャンプ
- BGMをつける

## 🧰 こまったときのヒント

### ブロックが見つからない！

| やりたいこと | カテゴリ | 色 |
|------------|---------|-----|
| 動かす、座標 | 動き | 青 |
| 見た目を変える | 見た目 | むらさき |
| 音を鳴らす | 音 | ピンク |
| くりかえし、もし | 制御 | オレンジ |
| キーが押された、色に触れた | 調べる | 水色 |
| 計算、乱数 | 演算 | 緑 |
| 変数、スコア | 変数 | オレンジ（濃い） |
| 旗クリック、メッセージ | イベント | 黄色 |

### うまく動かないとき

1. **🏁をもう一回クリック** — リセットされることがある
2. **コードを1つずつためす** — 全部いっぺんに作らない。少しずつ追加して確認
3. **ブロックの順番を確認** — 上から順に実行されるよ
4. **他の人の作品を見る** — https://scratch.mit.edu/explore/projects/games で検索して「中を見る」
5. **パパに見せる** — 「ここがおかしいんだけど」って説明するだけで解決することもある

### コードが長くなってごちゃごちゃ！

- コードエリアで右クリック → 「整理する」
- 使わないブロックはドラッグしてブロック置き場に捨てる
- スプライトごとにコードを分ける（全部1つのスプライトに書かない）
