# 🔘 おうちIoTボタン 作り方ガイド

ボタンをポチッと押すと、お小遣い手帳に「○○のお手伝いを1回ぶん」申請できる物理ボタンを作るガイド。
押すと承認待ち（pending）で申請が入り、親が承認するとポイントが確定する（Alexa申請やアプリからの申請と同じ仕組み）。

ラズパイ（Raspberry Pi）を使う方式。ラズパイは常時電源・常時ネット接続なので、電池切れの心配なし。

---

## 仕組み（ざっくり）

```
[物理ボタン] ──押す──> [ラズパイ] ──token送信──> [サーバー(Supabase)]
                                               └─> お小遣い手帳に申請（承認待ち）
```

- ボタンは「押されたことをラズパイに伝える」だけ
- ラズパイは「ボタンに割り当てた合言葉（token）をサーバーに送る」だけ
- 誰の・どの家事・何ポイントかは、ぜんぶ管理画面（admin.html）で決める
  → ラズパイの中身を書き換えなくても、管理画面から変更できる

---

## 1. 何を買えばいい？

最低限これだけでOK。ラズパイは既にあるものを使う。

| 品目 | おすすめ | 値段のめやす | 必須？ |
|------|---------|------------|--------|
| 押しボタン | アーケードボタン 30mm（ゲーセンのボタン） | 150〜600円/個 | ✅ 必須 |
| ジャンパー線 | メス-メス（ラズパイのピンに挿すタイプ） | 100〜300円 | ✅ 必須 |
| スピーカー | USB or 3.5mm（押したとき声で知らせる用） | 1,000円〜 | 任意 |
| ブレッドボード | ハンダ付けせず試作したい場合 | 200〜400円 | 任意 |

### ボタンの選び方

- **アーケードボタン 30mm** が子供用にベスト。大きい・押しやすい・頑丈・カラフル
- 色違いの **5〜10個セット（1,000〜1,800円くらい）** を買うと、子供ごと・家事ごとに色分けできてお得
- もっと大きくしたいなら 60mm や 100mm の特大ボタンもある（500〜3,000円）
- 「ハメ込み式」「ファストン端子」タイプだと、ジャンパー線を挿すだけでハンダ付け不要なことが多い

### 買う場所

- Amazonで「アーケードボタン 30mm セット」で検索
- AliExpressならさらに安い（届くまで2〜3週間）
- 合計 **1,000〜2,000円** あればボタン数個ぶん揃う

## 2. 配線（ハンダ付けなし）

ラズパイの電源を切った状態で、ジャンパー線でボタンとラズパイをつなぐ。
抵抗などの部品は不要（ラズパイの内部プルアップを使う）。

| ボタン | ラズパイのピン（GPIO） | 物理ピン番号 | つなぐ相手（GND） |
|--------|---------------------|-------------|------------------|
| ボタン1 | GPIO17 | 11番ピン | 9番ピン（GND） |
| ボタン2 | GPIO27 | 13番ピン | 14番ピン（GND） |

- ボタンには端子が2つある。片方を GPIO、もう片方を GND につなぐだけ
- どっちの端子をどっちにしても動く（向きは気にしなくてOK）
- ボタンを増やしたいときは GPIO5 / GPIO6 / GPIO13 / GPIO19 / GPIO26 などの空きピンを使う

> ピンの位置がわからないときは「Raspberry Pi GPIO ピン配置」で画像検索すると配置図が出る。

## 3. ラズパイのセットアップ

SSHでラズパイに接続して、以下を実行する（コピペでOK）。

```bash
git clone https://github.com/osho0625/okodukai_history.git
cd okodukai_history/raspi
bash button-setup.sh
```

これで必要なソフトが入り、自動起動サービス（`button`）が登録される。

詳しい手順やトラブル対処は、リポジトリの `raspi/BUTTON_README.md` も参照。
（ラズパイの基本セットアップがまだなら、先に「🍓 Raspberry Pi セットアップガイド」を済ませておく）

---

## 4. 管理画面でボタンを登録して「合言葉（token）」を発行

1. お小遣い手帳の **管理者ページ（admin.html）** を開く
2. 「**🔘 IoTボタン管理**」のセクションを開く
3. 「➕ 新しいボタンを登録」で設定を入力：
   - **ボタンの名前**：例「いろはのゴミ捨て」
   - **対象の子**：プルダウンから選ぶ
   - **家事の名前**：例「ゴミ出し」
   - **ポイント**：例 2
   - **クールダウン秒数**：連打防止の待ち時間（初期値30秒）
4. 「ボタンを登録」を押す
5. 一覧に出たボタンの「**URL / QR / テスト**」を開くと、そのボタンの **token（tok_xxxx…）** が入ったURLが表示される
   → この token を控える（コピーボタンあり）

---

## 5. token をラズパイに貼る

ラズパイで設定ファイルを開く：

```bash
nano ~/button/button-listener.py
```

`BUTTONS` の部分を、手順4で控えた token に書き換える：

```python
BUTTONS = [
    {"pin": 17, "token": "tok_ここに1つめのトークン", "voice": None},
    {"pin": 27, "token": "tok_ここに2つめのトークン", "voice": None},
]
```

- `pin` は配線したGPIO番号に合わせる
- 子供名・家事・ポイントはここには書かない（管理画面で管理するから）
- 保存したらサービスを再起動：

```bash
sudo systemctl restart button
```

## 6. 動作確認のやり方

### 方法A：管理画面の「テスト発火」（ボタン工作なしで今すぐ試せる）

物理ボタンを作る前でも、押したのと同じ動きを確認できる。

1. admin.html →「🔘 IoTボタン管理」
2. ボタンの「URL / QR / テスト」を開く
3. 「🧪 **テスト発火（1回申請してみる）**」を押す
4. 「✓ ○○の△△（Npt）を申請しました」と緑で出れば成功
5. すぐもう一度押すと「⏳ クールダウン中です」と出る（連打防止が効いている証拠）
6. 管理画面の承認待ち一覧に申請が入っているのを確認

### 方法B：実際のボタンを押す

1. ラズパイでログを表示：

   ```bash
   journalctl -u button -f
   ```

2. 物理ボタンを押す
3. ログに `🔘 押下` → `✅ ...を申請しました` が出れば成功
4. スピーカーをつないでいれば「○○くん、おてつだい申請したよ」と読み上げる
5. 管理画面の承認待ち一覧に申請が入る → 親が承認するとポイント確定

### うまくいかないとき

| 症状 | チェック |
|------|---------|
| 押しても無反応 | 配線（GPIOとGND）、ログに「押下」が出るか、tokenが未設定(`tok_REPLACE_ME`)のままでないか |
| `invalid_token` と出る | 管理画面で発行した token と一致しているか（前後の空白に注意） |
| `cooldown` ばかり出る | 仕様どおり。管理画面でクールダウン秒数を調整できる |
| 音が出ない | スピーカー・音声機能は任意。なくても申請自体は動く |

## 7. 運用のヒント

- **色で割り当て**：青＝お兄ちゃん、赤＝妹、みたいに色分けすると直感的
- **割り当て変更は管理画面だけ**：ポイントを変えたい・一時的に無効にしたいときは admin.html の「🔘 IoTボタン管理」でトグルや再登録すればOK。ラズパイはさわらなくていい
- **押下回数・最終押下**も管理画面に出るので、ちゃんと使われているか確認できる
- token が万一漏れても、そのボタンの申請（承認待ち）しかできないので安心。気になれば管理画面で削除して作り直せる
