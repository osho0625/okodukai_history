# 子供3人の自立心・自己肯定感 育成ロードマップ

## 基本方針

目的は「勉強ができるようにする」「将来の職業を決める」ではなく、  
**「自分で考えて行動し、失敗しても再挑戦できる子になること」** とする。

能力よりも、以下の経験を増やすことを重視する：

- 自分で決める
- 自分でやり切る
- 失敗から立ち直る

---

## 長男（小5）

### 特徴

- 言語能力が高い
- 頭脳労働が得意
- 論理的に考えることが得意
- マイクラで脱出ゲームを作る
- **失敗に弱い（できないと泣くことがある）**

### 育成テーマ

**「できる子」から「失敗しても挑戦できる子」へ**

能力は十分あるため、知識を増やすよりも失敗との付き合い方を学ぶことを優先する。

### プログラミングロードマップ

#### フェーズ1（1〜3ヶ月）：Scratch

**目的：**「プログラミングを学ぶ」ではなく「ゲームを作る」

**Scratch公式サイト：** https://scratch.mit.edu/

**アカウント作成手順：**
1. https://scratch.mit.edu/join にアクセス
2. ユーザー名とパスワードを決める（本名は使わない）
3. メールアドレスで確認（親のアドレスでOK）
4. プロフィールは非公開設定にする

**最初にやること（Week 1）：**
1. Scratchエディタを開く（https://scratch.mit.edu/projects/editor/）
2. 公式チュートリアル「はじめよう」を一緒にやる（https://scratch.mit.edu/projects/editor/?tutorial=getStarted）
3. ネコを動かす → キー操作で動かす → 壁に当たったら跳ね返る、を体験する

**作るもの（段階的に）：**

##### ステップ1：迷路ゲーム（Week 2〜3）

**やること：**
1. 背景に「迷路」を自分で描く（ペイントエディタで壁を黒、道を白で描く）
2. スプライト（キャラ）を小さくして迷路の入口に配置
3. 矢印キーで上下左右に動くコードをつける
   - 「🏁旗が押されたとき」→「ずっと」→「もし〈上向き矢印キーが押された〉なら」→「y座標を5ずつ変える」
   - 同様に下(-5)、右(x+5)、左(x-5)
4. 壁（黒色）に触れたら「スタート地点に戻る」処理を追加
   - 「もし〈色■に触れた〉なら」→「x座標を◯、y座標を◯にする」
5. ゴール地点にスプライトを置き、触れたら「やったー！」と言わせる

**学べること：** 座標、条件分岐、色判定、イベント

**参考：** Scratchコミュニティで「迷路」を検索すると他の人の作品を見て中身（コード）を確認できる → 「リミックス」文化を活用する

##### ステップ2：脱出ゲーム（Week 4〜5）

**やること：**
1. 複数の「部屋」を背景として用意する（背景を切り替えで場面転換）
2. アイテム（鍵など）をスプライトとして配置
3. アイテムを取ったら変数「鍵=1」にする
4. ドアスプライトに触れたとき「もし鍵=1なら」→「次の背景に切り替える」
5. メッセージ機能を使って「鍵GET」「ドア開く」など場面の連携を作る

**学べること：** 変数、メッセージ（イベント通信）、背景切替、状態管理

**マイクラ脱出ゲーム経験が活きるポイント：**
- 鍵を集めてドアを開ける仕組みは本人が得意な領域
- 「自分が作りたいゲームをScratchで作る」という動機づけになる

##### ステップ3：シューティングゲーム（Week 6〜8）

**やること：**
1. 自機スプライトを左右キーで移動させる
2. スペースキーで弾を発射（クローンを使う）
   - 「スペースキーが押されたとき」→「自分自身のクローンを作る」
   - 「クローンされたとき」→「◯の位置に行く」→「y座標を10ずつ変える（繰り返し）」→「端に触れたら削除」
3. 敵スプライトを上から落とす（これもクローンで複数出現）
4. 弾が敵に当たったらスコア+1 & 敵を削除
5. 敵が自機に当たったらゲームオーバー

**学べること：** クローン、スコア変数、当たり判定、ゲームループ

##### ステップ4：アクションゲーム（Week 9〜12）

**やること：**
1. 重力の概念を入れる（y座標を常に-2する＝落下）
2. 地面（色）に触れたら落下を止める
3. ジャンプ（スペースキーでy速度を+にする → 徐々に落ちる）
4. 横スクロール（背景をスクロールさせる or ステージを複数用意）
5. 敵やトゲに触れたらやり直し

**学べること：** 物理シミュレーション（簡易重力）、速度変数、ゲームデザイン

**Scratch便利リンク集：**
- チュートリアル集: https://scratch.mit.edu/ideas
- 他の人の作品を見る: https://scratch.mit.edu/explore/projects/games
- Scratch Wiki（日本語）: https://ja.scratch-wiki.info/

#### フェーズ2（3〜6ヶ月）：ゲーム設計

Scratchの前に**企画書**を書く。

**企画書テンプレート：**
| 項目 | 例 |
|---|---|
| ゲーム名 | 宇宙脱出大作戦 |
| 目的 | 宇宙船から脱出する |
| クリア条件 | 3つの鍵を集めて脱出ポッドに乗る |
| 難しいポイント | 敵ロボットを避ける、制限時間あり |
| ステージ数 | 3面 |

**なぜ企画書を書くか：**
- 「作りながら考える」から「考えてから作る」へステップアップ
- 論理的思考力は高いので、この工程は得意なはず
- 完成像を持つことで「できた/できてない」が明確になり、達成感につながる

## 次女（小3）

### 特徴

- 工作好き
- マイクラ建築好き
- ハサミで色々切る
- 分解欲求が強い
- 片付けが苦手

### 育成テーマ

**「作る自由」と「作る責任」を学ぶ**

工作は禁止しない。代わりにルールを作る。

### ルール

**工作OKボックス（入れてよいもの）：**
- 段ボール
- 牛乳パック
- 空き箱
- 廃材

**工作NG：**
- 財布
- 教科書
- ランドセル
- 家族の私物

**片付けルール：** 工作後5分だけ片付ける。
