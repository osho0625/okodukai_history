# 結婚式に向けた9か月ボディメイク計画

## 目標

| 項目 | 内容 |
|------|------|
| 現在年齢 | 31歳 |
| 身長 | 173cm |
| 体重 | 61kg |
| トレーニング | 自重中心 |
| 結婚式 | 約9か月後（2027年4〜5月頃） |

### 基本方針

- 無理なダイエットは行わない
- 「体重を減らす」より「筋肉を増やして体型を整える」ことを優先
- タキシード・スーツ姿を意識し、肩・胸・背中・腕・腹部・姿勢を重点的に鍛える

### 数値目標

- 体重：62〜65kg程度を目安
- 腹囲を増やしすぎない
- 肩・胸・背中を発達させる
- 姿勢を改善する
- **体重の数値より見た目を優先**

- ジャンプして懸垂姿勢になり、ゆっくり降りる（ネガティブ懸垂）

- から始める

## 進め方（プログレッション）

単純に回数を増やし続けるのではなく、**同じ回数を余裕を持ってできるようになったら種目の難易度を上げる**。

例：腕立て伏せ
1. 普通の腕立て
2. 回数を増やす
3. 足を高くした腕立て
4. より難しいバリエーション

**「前回より少しだけ難しくする」ことが重要。**

## 9か月間のマイルストーン

### 1〜2か月目（8〜9月）：基礎作り

- 自重トレーニングの習慣を作る
- 週3回を目標
- A/Bメニューを継続
- 各種目のフォームを覚える
- 無理に回数を増やさない

### 3〜6か月目（10〜1月）：筋肉を本格的に増やす

- 10月から懸垂を導入
- 特に懸垂・腕立て・パイクプッシュアップ・ブルガリアンスクワットを継続
- 徐々に回数・難易度を上げる

### 7〜8か月目（2〜3月）：体型を仕上げる

- 毎月、正面・横・背面の写真を同じ条件で撮影
- 体型の変化を確認（体重だけで判断しない）

### 9か月目（4〜5月）：最終調整

- 腹囲や見た目を確認
- まだ細い → 筋肉を増やす方向を継続
- 腹周りが気になる → 食事を少し調整
- 体型に満足 → 現状維持
- **結婚式直前に極端な減量は行わない**

- **体重より見た目を優先**

## 姿勢

筋トレと同じくらい重要。結婚式では写真を多く撮るため、姿勢が見た目に大きく影響する。

### 意識すること

- 猫背・巻き肩・首が前に出る・骨盤の傾きを改善
- 胸を軽く開く
- 肩をすくめない
- 頭を前に出さない
- お腹を軽く引き締める

---

## やらないこと

結婚式直前に以下は行わない：

- 極端な食事制限
- 極端な糖質制限
- 水分を極端に減らす
- 急に筋トレ量を増やす
- 直前の無理な減量

**9か月かけて少しずつ体型を作り、最後はコンディションを整える。**

---

## 最終目標

目指すのは「体重が軽い人」ではなく、**「細身だけど肩・胸・背中がしっかりしていて、腹が出ていない人」**。

173cm・61kgの体格なら：
1. 自重トレーニング
2. 10月から懸垂追加
3. 食事で十分なタンパク質
4. 9か月継続

で到達可能。ダンベルは必須ではない。懸垂バーがあれば自重だけで上半身をバランスよく鍛えられる。
