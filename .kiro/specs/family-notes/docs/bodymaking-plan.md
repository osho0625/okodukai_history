# 結婚式に向けた9か月ボディメイク計画

## 目標

| 項目 | 内容 |
|------|------|
| 現在年齢 | 31歳 |
| 身長 | 173cm |
| 体重 | 61kg |
| トレーニング | 自重中心 |
| 結婚式 | 約9か月後（2027年4〜5月頃） |

### 基本方針

- 無理なダイエットは行わない
- 「体重を減らす」より「筋肉を増やして体型を整える」ことを優先
- タキシード・スーツ姿を意識し、肩・胸・背中・腕・腹部・姿勢を重点的に鍛える

### 数値目標

- 体重：62〜65kg程度を目安
- 腹囲を増やしすぎない
- 肩・胸・背中を発達させる
- 姿勢を改善する
- **体重の数値より見た目を優先**

## 各種目のやり方

<details>
<summary>💪 腕立て伏せ（プッシュアップ）</summary>

**鍛える部位：** 胸・肩前部・三頭筋

**正しいフォーム：**
1. 手を肩幅より少し広めに床につく
2. 指先はやや外向き、手首の真上に肩がくる位置
3. 頭からかかとまで一直線を保つ（お尻を上げない・腰を反らない）
4. 肘を曲げて胸を床に近づける（肘の角度は約45度に開く）
5. 胸が床すれすれまで下ろしたら、押し上げて戻る

**呼吸：** 下ろすとき吸う → 押し上げるとき吐く

**よくある間違い：**
- お尻が上がっている（体幹に力が入っていない）
- 腰が反っている（腹筋を締める意識が足りない）
- 肘を真横に開きすぎ（肩を痛める原因）
- 首だけ動かして胸を下ろしていない

**まだきつい場合：** 膝をついた状態から始めてOK。フォームが崩れるより膝つきで正しい姿勢を覚える方が大事。

</details>

<details>
<summary>💪 ナロープッシュアップ</summary>

**鍛える部位：** 三頭筋（二の腕）・胸の内側

**正しいフォーム：**
1. 手の幅を肩幅より狭くする（指先が触れるくらいでもOK）
2. 手の位置は胸の下あたり
3. 肘を体に沿わせるように曲げる（横に開かない）
4. 体は頭からかかとまで一直線
5. 胸を手の間に下ろし、三頭筋で押し上げる

**呼吸：** 下ろすとき吸う → 押し上げるとき吐く

**よくある間違い：**
- 肘を外に開いてしまう（通常の腕立てになってしまう）
- 手の位置が顔の前すぎる（肩に負担がかかる）
- 可動域が浅い（しっかり下まで下ろす）

**ポイント：** 通常の腕立てより難しいので、回数が少なくてもOK。フォーム優先。

</details>

<details>
<summary>💪 パイクプッシュアップ</summary>

**鍛える部位：** 肩（三角筋前部・中部）・三頭筋

**正しいフォーム：**
1. 腕立ての姿勢からお尻を高く上げ、体を「く」の字にする
2. 手の幅は肩幅かやや広め
3. 頭を両腕の間に入れるように、肘を曲げて頭を床に近づける
4. 肘は前方やや外側に曲がる
5. 頭が床に触れそうなところまで下ろし、押し上げる

**呼吸：** 下ろすとき吸う → 押し上げるとき吐く

**よくある間違い：**
- お尻が十分に上がっていない（ただの腕立てになる）
- 肘を真横に開く（肩を痛める）
- 腰が曲がったまま動作する（股関節で折る、背中は伸ばす）

**強度を上げるには：** 足を椅子やベッドに乗せて角度をつける（デクラインパイクプッシュアップ）。

</details>

<details>
<summary>💪 ブルガリアンスクワット</summary>

**鍛える部位：** 大腿四頭筋・臀筋・ハムストリング

**正しいフォーム：**
1. 椅子やソファの前に立ち、片足の甲を後ろの台に乗せる
2. 前足は台から60〜90cm程度離す
3. 上体をやや前傾させ、前足の膝を曲げて腰を落とす
4. 前足の膝がつま先より大きく前に出ないよう注意
5. 前足のかかとで地面を押し、元の位置に戻る

**呼吸：** 下ろすとき吸う → 立ち上がるとき吐く

**よくある間違い：**
- 前足が台に近すぎる（膝が前に出すぎる）
- 上体が直立しすぎ（腰に負担）
- 後ろ足に体重を乗せすぎ（前足で支える意識）
- 膝が内側に入る（つま先と同じ方向に膝を向ける）

**バランスが取れない場合：** 壁や柱に軽く手を添えてOK。慣れたら手を離す。

</details>

<details>
<summary>💪 スクワット</summary>

**鍛える部位：** 大腿四頭筋・臀筋・ハムストリング・体幹

**正しいフォーム：**
1. 足を肩幅に開き、つま先はやや外向き（30度程度）
2. 胸を張り、背中をまっすぐ保つ
3. お尻を後ろに引くように腰を落とす（椅子に座るイメージ）
4. 太ももが床と平行になるまで下げる
5. かかとで地面を押して立ち上がる

**呼吸：** 下ろすとき吸う → 立ち上がるとき吐く

**よくある間違い：**
- 膝がつま先より大きく前に出る（お尻を引く意識が足りない）
- 背中が丸まる（胸を張る・視線を前に）
- かかとが浮く（足裏全体で踏む）
- 膝が内側に入る（つま先と同じ方向に）

**ポイント：** 自重スクワットで25回が楽にできるようになったら、テンポを遅くする（3秒かけて下ろす）ことで負荷を上げる。

</details>

<details>
<summary>💪 リバースランジ</summary>

**鍛える部位：** 臀筋・大腿四頭筋・ハムストリング

**正しいフォーム：**
1. まっすぐ立ち、片足を後ろに大きく引く
2. 両膝を90度に曲げて腰を落とす
3. 前足の膝がつま先より前に出ない
4. 後ろの膝が床すれすれまで下げる
5. 前足のかかとで地面を押し、元の位置に戻る

**呼吸：** 足を引いて下ろすとき吸う → 戻るとき吐く

**よくある間違い：**
- 歩幅が狭い（膝が90度にならない）
- 上体が前に倒れすぎ（体幹をまっすぐ）
- 着地が不安定（ゆっくり動作する）

**前方ランジとの違い：** 後ろに引く方が前膝への負担が少なく、バランスも取りやすい。初心者にはリバースランジの方がおすすめ。

</details>

<details>
<summary>💪 ヒップリフト（グルートブリッジ）</summary>

**鍛える部位：** 臀筋・ハムストリング・脊柱起立筋

**正しいフォーム：**
1. 仰向けに寝て、膝を90度に曲げ、足裏を床につける
2. 足は腰幅、かかとはお尻から近すぎず遠すぎない位置
3. お尻を締めながら腰を持ち上げる
4. 肩から膝まで一直線になるまで上げる
5. トップで1〜2秒キープし、ゆっくり下ろす

**呼吸：** 上げるとき吐く → 下ろすとき吸う

**よくある間違い：**
- 腰を反りすぎ（肩〜膝が一直線でストップ）
- 太ももの前や腰で上げている（お尻を締める意識）
- テンポが速すぎる（ゆっくり上げてキープ）

**強度を上げるには：** 片足ヒップリフト（片足を伸ばした状態で行う）に進む。

</details>

<details>
<summary>💪 プランク</summary>

**鍛える部位：** 腹横筋・腹直筋・脊柱起立筋（体幹全体）

**正しいフォーム：**
1. うつ伏せから、肘とつま先で体を支える
2. 肘は肩の真下に置く
3. 頭からかかとまで一直線を保つ
4. お腹を軽くへこませる（ドローイン）
5. お尻を上げない・腰を反らない

**呼吸：** 止めない。自然に呼吸を続ける。

**よくある間違い：**
- お尻が上がっている（鏡や動画で確認）
- 腰が反っている（腹筋に力を入れる）
- 肩がすくんでいる（肩を下げる意識）
- 息を止めている（浅くてもいいので呼吸する）

**ポイント：** 60秒が楽にできるようになったら、時間を伸ばすより片手・片足を上げるバリエーションに進む方が効果的。

</details>

<details>
<summary>💪 サイドプランク</summary>

**鍛える部位：** 腹斜筋・腹横筋・中殿筋

**正しいフォーム：**
1. 横向きに寝て、肘を肩の真下につく
2. 下の足から頭まで一直線になるように腰を持ち上げる
3. 上の手は腰に当てるか天井に伸ばす
4. 骨盤が前後に回転しないようキープ
5. 足は重ねるか、上の足を前に出して安定させる

**呼吸：** 止めない。自然に呼吸を続ける。

**よくある間違い：**
- 腰が落ちている（体が一直線になっていない）
- 骨盤が前に倒れている（横から見て体が一枚板）
- 肘の位置がずれている（肩の真下）

**まだきつい場合：** 膝を曲げて膝下を床につけた状態で行う（ハーフサイドプランク）。

</details>

<details>
<summary>💪 懸垂（チンアップ / プルアップ）</summary>

**鍛える部位：** 広背筋・大円筋・上腕二頭筋・前腕

**正しいフォーム：**
1. バーを肩幅よりやや広く握る（順手=プルアップ、逆手=チンアップ）
2. 肩甲骨を下げて胸を張る（ぶら下がった状態で肩をすくめない）
3. 肘を体の横〜やや後ろに引くように体を引き上げる
4. あごがバーの上に来るまで上げる
5. ゆっくり腕を伸ばして下ろす（完全に伸ばしきる）

**呼吸：** 引き上げるとき吐く → 下ろすとき吸う

**よくある間違い：**
- 体を振って反動で上げる（キッピング）
- 肩がすくんだまま引く（肩甲骨を下げてから引く）
- 下ろすとき一気に落ちる（ゆっくり下ろす=筋力アップに重要）
- 可動域が狭い（しっかり上まで上げ、下まで伸ばす）

**まだできない場合の練習法：**
1. **ネガティブ懸垂**：ジャンプしてトップ位置に上がり、5秒かけてゆっくり下ろす
2. **足補助懸垂**：椅子に片足を乗せて補助しながら引き上げる
3. **斜め懸垂**：低いバーやテーブルの下で、体を斜めにして引く

**順手 vs 逆手：**
- 順手（プルアップ）：背中への刺激が大きい
- 逆手（チンアップ）：二頭筋も使えるのでやや楽、初心者向け

</details>

## 進め方（プログレッション）

単純に回数を増やし続けるのではなく、**同じ回数を余裕を持ってできるようになったら種目の難易度を上げる**。

例：腕立て伏せ
1. 普通の腕立て
2. 回数を増やす
3. 足を高くした腕立て
4. より難しいバリエーション

**「前回より少しだけ難しくする」ことが重要。**

## 9か月間のマイルストーン

### 1〜2か月目（8〜9月）：基礎作り

- 自重トレーニングの習慣を作る
- 週3回を目標
- A/Bメニューを継続
- 各種目のフォームを覚える
- 無理に回数を増やさない

### 3〜6か月目（10〜1月）：筋肉を本格的に増やす

- 10月から懸垂を導入
- 特に懸垂・腕立て・パイクプッシュアップ・ブルガリアンスクワットを継続
- 徐々に回数・難易度を上げる

### 7〜8か月目（2〜3月）：体型を仕上げる

- 毎月、正面・横・背面の写真を同じ条件で撮影
- 体型の変化を確認（体重だけで判断しない）

### 9か月目（4〜5月）：最終調整

- 腹囲や見た目を確認
- まだ細い → 筋肉を増やす方向を継続
- 腹周りが気になる → 食事を少し調整
- 体型に満足 → 現状維持
- **結婚式直前に極端な減量は行わない**

- 毎朝、同じ条件で体重を測る
- 月0.3〜0.5kg程度の増加を想定

| 月 | 目安体重 |
|----|----------|
| 8月 | 61.0kg |
| 9月 | 61.3kg |
| 10月 | 61.7kg |
| 11月 | 62.1kg |
| 12月 | 62.5kg |
| 1月 | 62.8kg |
| 2月 | 63.2kg |

### 判断基準

- 筋力も体重も増えない → 食事量を少し増やす
- 腹囲が大きくなっている → 食べる量を少し減らす
- **体重より見た目を優先**

## 姿勢

筋トレと同じくらい重要。結婚式では写真を多く撮るため、姿勢が見た目に大きく影響する。

### 意識すること

- 猫背・巻き肩・首が前に出る・骨盤の傾きを改善
- 胸を軽く開く
- 肩をすくめない
- 頭を前に出さない
- お腹を軽く引き締める

---

## やらないこと

結婚式直前に以下は行わない：

- 極端な食事制限
- 極端な糖質制限
- 水分を極端に減らす
- 急に筋トレ量を増やす
- 直前の無理な減量

**9か月かけて少しずつ体型を作り、最後はコンディションを整える。**

---

## 最終目標

目指すのは「体重が軽い人」ではなく、**「細身だけど肩・胸・背中がしっかりしていて、腹が出ていない人」**。

173cm・61kgの体格なら：
1. 自重トレーニング
2. 10月から懸垂追加
3. 食事で十分なタンパク質
4. 9か月継続

で到達可能。ダンベルは必須ではない。懸垂バーがあれば自重だけで上半身をバランスよく鍛えられる。
