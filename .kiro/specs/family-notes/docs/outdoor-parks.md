## 備考

- あいかわ公園の駐車場はかなり広い。普通車500円。平日は無料、土日祝や長期休暇期間は有料。

## おすすめ順位

### 1位：Aikawa Park（無料でガッツリ遊びたいなら）

- アスレチック◎
- 長い滑り台◎
- 水遊び場あり（夏季）◎
- ダム見学もできる
- 小学生が一番満足しやすい

### 2位：綾瀬市こどもドリームプレイウッズ（泥んこ遊びしたいなら）

- 泥遊び・水遊び・木工作
- 自由度高い
- ただし「アスレチック施設」ではなくプレーパーク寄り

### 3位：Field Athletics Yokohama Tsukushino course（お金払ってもいいなら）

- 池ポチャあり
- 水上アスレチックあり
- 泥だらけになれる
- 川和町から近い
- 「泥に落ちるやつ」のイメージに最も近い

## 満足度（小学1〜4年生の場合）

1. あいかわ公園
2. つくし野フィールドアスレチック
3. ドリームプレイウッズ

## 追加スポット詳細

### 金沢自然公園（横浜市金沢区）

- 住所：神奈川県横浜市金沢区釜利谷東5-15-1
- 約60万㎡の広大な敷地。「植物区エリア」と「動物園エリア」に分かれる
- **遊具の特徴**：
  - 「こども広場」にアスレチック遊具約10点
  - ネットのトンネル、アーチ状のはしご
  - 約100mのロングローラーすべり台（お尻が痛くなるのでソリ持参推奨）
  - 小さい子向けのゆるいローラーすべり台もあり
- 動物園にはゾウ・キリン・コアラ・カンガルーなど約50種
- ヤギ・ヒツジとのふれあい「ほのぼの広場」あり
- **入園料**：公園は無料。動物園は大人500円・高校生300円・小中学生200円（毎週土曜は学生証提示で小中高無料）
- **駐車場**：正面口 1回600円 / 高速側にも駐車場あり
- **休園日**：公園は無休。動物園は月曜（祝日の場合翌日）・年末年始
- **アクセス**：京急「金沢文庫駅」からバス「夏山坂上」下車徒歩6分

### 神奈川県立三ツ池公園（横浜市鶴見区）

- 住所：神奈川県横浜市鶴見区三ツ池公園1-1
- 3つの池を豊かな樹林が囲む県立公園
- **遊具の特徴**：
  - 「遊びの森」エリアのアスレチック遊具（うんてい・はしご・長いネット）
  - 全長67.3mのロングすべり台（一番人気。登り口までの道が土面で滑りやすい）
  - 幅の広いコンクリートのジャンボすべり台
- 春は約1,000本の桜が咲く花見スポットとしても人気
- **入園料**：無料
- **駐車場**：あり（正門・北門の2か所、約146台）。1回510円（花見時期や繁忙期は830円）
- **休園日**：無休
- **アクセス**：JR京浜東北線「鶴見駅」から臨港バス07系統「三ツ池公園」行きで約15分

### こども自然公園（横浜市旭区）

- 住所：神奈川県横浜市旭区大池町65-1
- 通称「大池公園」。横浜市内最大級の面積を持つ公園
- **遊具の特徴**：
  - 「とりでの森」エリアに大型アスレチック遊具（6〜12歳対象）
  - 全身を使う仕掛け＋頂上からのロングすべり台が人気
  - 焼き芋体験（落ち葉を集めて焼く。さつまいもは現地販売あり）
- 「万騎が原ちびっこ動物園」で小動物とふれあい可能（要事前予約）
- ピクニック広場・バーベキュー広場あり
- **入園料**：無料
- **駐車場**：あり（第1・第2）。2時間300円、以降20分50円
- **休園日**：無休（動物園は月曜休）
- **アクセス**：相鉄本線「二俣川駅」南口から徒歩約15分。車は保土ヶ谷バイパス「南本宿IC」から約1km

### こどもの国（横浜市青葉区）

- 住所：神奈川県横浜市青葉区奈良町700
- 東京ドーム21個分の広大な敷地。子供向けレジャー施設の定番
- **遊具の特徴**：
  - 全長115mのローラーすべり台（市内最長。6〜12歳対象）
  - 恐竜テーマの遊具広場「タイムトラベル」（ちびっこゾーン3〜6歳、わんぱくゾーン6〜12歳）
  - 立体迷路「キュービックランド」（6〜12歳）
  - 0歳から遊べる「すくすくアイランド」
  - 色々な形の自転車コーナー
- ふれあい動物園、プチジェットコースターあり
- 夏はプール、冬はアイススケート場
- **入園料**：大人600円・小中学生200円・3歳以上100円
- **駐車場**：正面820台＋臨時（牧場口）700台。1回1,000円
- **開園時間**：9:30〜16:30（夏季17:00まで）。駐車場8:30〜開場
- **休園日**：水曜（祝日除く）・年末年始
- **注意**：土日祝はかなり混雑。電車推奨。こどもの国線「こどもの国」駅徒歩3分

### 岸根公園（横浜市港北区）

- 住所：神奈川県横浜市港北区岸根町725
- 地下鉄ブルーライン「岸根公園」駅直結。川和町からのアクセス◎
- **遊具の特徴**：
  - 大型複合遊具「忍者とりで」（吊り橋・ネットアスレチック・トンネル・ローラーすべり台が組み合わさった遊具）
  - 幅広い年齢で遊べる
- 「篠原池」で春はお花見、「ひょうたん原っぱ」で芝生ピクニック
- **入園料**：無料
- **駐車場**：あり。20分100円
- **休園日**：無休
- **アクセス**：市営地下鉄「岸根公園」駅2番出口すぐ。川和町から車で約15〜20分

### さがみ湖MORI MORI（相模原市緑区）

- 住所：神奈川県相模原市緑区若柳1634
- 旧称「さがみ湖リゾート プレジャーフォレスト」。2024年7月に名称変更
- 遊園地・アスレチック・キャンプ・BBQ・温泉が一体になった複合レジャー施設
- **遊具・アトラクションの特徴**：
  - 「マッスルモンスター2」：標高370m、地上16.1mの巨大クライミングアトラクション（身長120cm以上）
  - 「鼻つまみ天狗」：空中アスレチック（5階建て巨大立体迷路付き）
  - パディントンタウン（未就学〜小学低学年向け）
  - じゃぶじゃぶパラダイス（夏季限定の水遊びエリア）
  - 冬はスノーパラダイス（雪遊び）・イルミネーション
- **入園料**：大人1,900〜2,300円・小人1,200〜1,600円（ダイナミックプライシングで日により変動）
- **フリーパス**：大人4,500円・小人3,700円
- **駐車場**：あり。1回1,000円
- **営業時間**：9:00〜17:00（時期・曜日により変動）
- **休園日**：不定休（公式サイト要確認）
- **アクセス**：JR中央本線「相模湖」駅からバス約10分「さがみ湖MORIMORI前」下車。車は相模湖ICから約15分
- **注意**：土日祝・GW・連休はかなり混雑。フリーパスがあっても1アトラクション15〜30分待ちの場合あり

### ツリークロスアドベンチャー（厚木市七沢）

- 住所：神奈川県厚木市七沢2758 福元館前階段奥の山中
- 東丹沢・七沢温泉郷に隣接する本格的な樹上アドベンチャーパーク
- **コースの特徴**：
  - 「アドベンチャーコース」：樹上5〜15mに連なる42個の障害物を命綱で攻略＋最長173mの谷越えジップライン（所要約2時間）
  - 「アスレチックコース」：未就学児向けの低難度コース
  - 特別な技術不要。命綱（ハーネス）着用で安全
- **対象年齢**：アドベンチャーコースは小学3年生以上。中学生以下は保護者同伴必須
- **料金**：
  - アドベンチャーコース：18歳以上3,800円・17歳以下2,800円（予約定員制）
  - アスレチックコース：未就学児700円・付添い者700円
- **営業時間**：
  - 2月〜10月：平日10:00〜17:00 / 休日9:00〜17:00（最終受付15:00）
  - 11月〜1月：平日10:00〜16:30 / 休日9:00〜16:30（最終受付14:00〜14:30）
- **休業日**：3〜11月無休 / 12〜2月は水曜定休
- **駐車場**：専用駐車場なし（近隣の七沢温泉郷周辺を利用）
- **アクセス**：新東名・伊勢原大山ICから約10分。小田急「本厚木駅」東口9番バス乗り場から系統33・34で「広沢寺温泉入口」下車徒歩20分
- **注意**：予約制のため事前にWebから予約が必要。雨天・強風時は中止の場合あり

- 「夏に水遊びできる公園」を条件に入れると、相模原・海老名・座間方面にも候補あり。

- こどもの国の駐車場は先払い・キャッシュレス対応。入場後の払い戻し不可。
