# 🪀 けん玉ロードマップ

## 目的

けん玉が上手になることではなく、

- **できないことに挑戦する**
- **失敗しても続ける**
- **少しずつ上達する**

経験を積むことを目的とする。

特に三男の「できない → べそをかく」を「できない → 練習する → できる」へ変えていく。

---

## 基本ルール

### ルール1：親も一緒にやる

先生と生徒ではなく、**挑戦仲間**になる。

### ルール2：競争しない

| NG | OK |
|---|---|
| 誰が一番上手いか | 家族で何回成功したか |
| 誰が勝ったか | 先月よりできるようになったか |

### ルール3：結果より過程を褒める

| NG | OK |
|---|---|
| すごい！上手い！ | 続けたね |
| - | 諦めなかったね |
| - | 昨日より上手くなったね |

## 最終目標

けん玉を通じて：

- **できない状態に耐える**
- **失敗しても続ける**
- **少しずつ成長する**

習慣を身につける。

技の数よりも、**挑戦し続ける姿勢**を重視する。
