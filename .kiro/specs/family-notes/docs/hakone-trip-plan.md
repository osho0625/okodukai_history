# 箱根旅行計画（2026年10月末〜11月上旬予定）

## 基本情報

### 参加者
- 大人：3〜4名
  - 涼介
  - めぐみ
  - お義父さん（参加の場合あり）
  - お兄さん（未定）
- 子供：3名
  - はるちか（小5）
  - いろは（小3）
  - かいせい（小1）

### 日程
- 1泊2日予定

### 予算目安
- 宿泊＋主要レジャー：10万円程度希望
- 旅行全体：15〜20万円程度

### 目的
- 子供が楽しめる旅行
- 大人も温泉や観光を楽しむ
- 妻の父が参加する場合でも満足できる内容にする

### 概要

△ 子供が作品鑑賞を主体として楽しむには難しい可能性がある

- 作品を見る時間が長くなりにくい
- 「何が楽しいか」が分かりにくい可能性がある

今回の旅行では、子供が明確に楽しめる体験型スポットを優先するため候補外。

### 再検討する条件
- 子供が美術やアートに興味を持った場合
- 大人中心の箱根旅行の場合
