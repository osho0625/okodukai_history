# クアルト - 要件

## 概要
2人用ボードゲーム。4×4ボードに16個のピースを交互に置く。
4つの属性（大/小、明/暗、丸/四角、穴あり/穴なし）のうち1つが4つ揃ったら「クアルト！」で勝利。

## 要件

### FR-1: ゲームルール
- 16ピース（4属性×2値 = 2^4 = 16通り全て異なる）
- 相手が選んだピースを自分が置く
- 4つ揃い（行/列/対角線）で勝利宣言
- 全ピース配置で揃いなければ引き分け

### FR-2: プレイモード
- 2人対戦（同一端末パス&プレイ）

### FR-3: UI
- 4×4ボード表示
- 残りピース一覧
- ターン表示（「ピースを選ぶ」/「ピースを置く」）
- 勝利/引き分け演出

### FR-4: 制約
- 夜間制限対応
- DB不使用
- 単一HTMLファイルで完結
